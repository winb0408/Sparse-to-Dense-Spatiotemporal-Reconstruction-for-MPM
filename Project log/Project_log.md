## SPUR-E000a — 仓库底座搭建（无数据）

- **日期**：2026-10-27
- **Git**：`research/spur-mpm-v1`（仓库初始化后的首个提交）
- **阶段**：Phase 0 前置（底座），**不是**数据审计，不产生任何科学结论
- **目的**：在 Dryad 数据下载完成前，把「一个输入 → 一次重建 → 一次评估」的完整竖切跑通，

  写成**结构性约束**而不是口头约定。

### 改动（新建模块）

| 层 | 文件 | 约束落点 |
|---|---|---|
| 物理 | `physics/psf.py` `sampling.py` `acquisition.py` `wiener.py` | 恒等 PSF 为默认（真实数据自带光学）；`M_acq` 定义为全局晶格 `(g-phase)%k==0` |

| 模型 | `models/{attention,swin_unet_2d,prior_fusion,uncertainty,registry}.py` | A0/A1/S0-S2/SS0-SS2/SS2g/S1g 由同一 backbone + 配置臂区分 |
| 损失 | `losses/{reconstruction,data_consistency}.py` `ssl/mms.py` | MMS 目标是**真实含噪测量**，不是稠密参考、不是零 |
| 评估 | `metrics/{image_metrics,vessel,statistics}.py` | PSNR/SSIM/MAE + E_measured/E_missing + Dice/clDice + 分组 bootstrap |
| 脚本 | `scripts/{make_synthetic,audit_data,make_split,prepare_data}.py` `train.py` `evaluate.py` `inference.py` | 合成数据全程标注 `SYNTHETIC_SMOKE`，不作为任何证据 |

### 配置

`spur_mpm/configs/base.yaml`：恒等 PSF（`sigma_*_um: 0.0`，`voxel_xy_um: 0.98`，`voxel_z_um: 5.0`）、
`u_kind: geo`、`geo_mode: per_axis`、MMS `ratio 0.5 / geometry row`；
实验臂 `E001`（A0/A1）、`E002`（S0/S1/S2）、`E003`（SS0/SS1/SS2）。

### 结果

1. **单元测试全绿**：`python -m pytest spur_mpm/tests -q` → 68 passed。
   含泄漏决定性测试：扰动 `y_hold` 后 `y/mask/x0/confidence/uncertainty` 五个输入字段逐位不变。
2. **合成数据竖切跑通**（3 只鼠 × 2 FOV，12×96×96，全程 CPU）：
   生成 → 审计（0 issues）→ LOMO 划分（3 folds，fingerprint `2f41252d…`）→ prepare（6 卷，标定 offset 0.0 / scale 585.5）
   → S1 训练 20 步（dense_psnr 5.87 → 13.25）→ SS1 训练 20 步（holdout_loss 0.422 → 0.202）
   → A1 基线评估（clDice 0.955）→ 整卷推理（输出 `.npy` + `.mask.npy` + `.warmstart.npy` + 元数据 JSON）。
3. 竖切过程中暴露并修复的真实缺陷（均已进测试）：
   - `_distance_to_measured` 的 `cummax` 哨兵值取 `+n`：第一个测量之后的索引全部退化为距离 `n`，轴向间隙一律饱和到 1；
   - `yz` 采样误用了面内 `grid` 晶格（`rows | cols`），实际体素比例 0.375 ≠ 1/(ky·kz)=0.25；
   - `build_model_inputs` 依赖调用方「已把非测量位置清零」，改为在此处强制 `y * M_in`；
   - manifest 的 `path` 相对**数据根**而非 manifest 所在目录，`prepare` 原来按 manifest 目录解析，导致全部跳过；
   - 校准 `apply` 含 `clip(0,1)`，`inverse` 却宣称精确可逆：改为显式声明「在标定区间内可逆」，并新增 `saturated_fraction()` 报告饱和比例。

### 结论

底座可用，但**没有任何 SPUR 科学结论**。上述所有数字来自合成数据与 20 步训练，仅证明管线连通性。

## SPUR-E000 — Dryad 3PM 真实数据审计与泄漏隔离

- **日期**：2026-10-28
- **Git**：`research/spur-mpm-v1`
- **阶段**：Phase 0
- **数据**：`/ssd1/wjb/Data/Dryad_3PM`（DOI 10.5061/dryad.wh70rxx2j）
- **产物**：`spur_mpm/experiments/E000_data_audit/{manifest.csv,manifest.json,audit_report.md,split.json}`、
  `data_local/dryad_cache/`（10 卷 `.npy` + `index.json` + `calibration_fold{0,1,2}.json`）
- **目的**：先读数据自带说明，再回答两个问题——**(a) 这批数据能怎么用；(b) 泄漏边界在哪、如何用代码锁死**。

### 数据本身（README + 逐文件核对）

APP NL-G-F 小鼠，Texas Red 标血管 + methoxy-XO4 标斑块，同一只鼠**相隔 4 周**成像两次；
XY 0.98 µm，Z 步长 5 µm（血管/斑块）与 10 µm（神经元），成像深度约 0–900 µm，激发 1340 nm。
另有 GFP 神经元片层与 6 张新生鼠肺图像（功率稳定性标定用）。

29 个 TIFF → **10 纳入 / 19 排除 / 3 组像素级重复 / 0 未解决 issue**。

### 泄漏边界与处置（本次审计的核心）

| 泄漏轴 | 具体情况 | 处置 |
|---|---|---|
| **动物** | 只有 3 只鼠（M1/M2/M3），M3 仅 1 个 FOV | 测试集按**留一鼠**，不做单文件随机划分 |
| **纵向 session** | 同一 FOV 的 Session 1/2 是同一批血管，相隔 4 周 | S1/S2 视为同一 `inner_key=(mouse, fov)`，**不跨 train/val** |
| **FOV** | 每鼠 1–2 个视野 | 验证集 = 剩余动物中的**一个完整 FOV（含两个 session）** |
| **通道** | 血管与斑块来自**同一次扫描** | 斑块通道全部排除：跨通道复用会泄漏组织身份 |
| **重复文件** | `Fig 3/3a Vessels.tif` 与 `M2_FOVII_S1_vessels` 像素完全一致；`Fig 3/3a Plaques.tif` 同理；`M3_FOVI_S2_plaques` 与 `M2_FOVI_S2_plaques` 像素完全一致（**跨动物**） | 像素级指纹 `content_fingerprint()`（sha256 over shape+dtype+bytes）自动识别；重复项一律 `use=excluded` |
| **时间轴** | 6 张新生鼠肺是 `TYX` 时间序列 | 明确拒绝进入 3D 管线（`GeometryError`），留给 Phase 6 钙成像 |
| **图版文件** | `Fig 3/*`、`3b - GFP neurons` 是从数据集中派生的插图 | 全部排除，且它们本身缺少 mouse/session/fov 标签 |

**为什么必须做像素指纹而不是文件哈希**：`Fig 3/3a Vessels.tif` 与原始卷的 TIFF 头（ImageJ 元数据）不同，
字节哈希不同，但像素完全相同。只比文件大小或 md5 会漏掉这类泄漏。

**标定必须是 per-fold**：`offset/scale` 用训练动物的分位数拟合。若用单一全局标定，
fold 1/2 的测试动物会以**自身统计量**归一化，测试集信息通过归一化常数回流。
现在 `VolumeCache.load(fold=f)` 在载入时选择该 fold 的标定，未登记则 `KeyError` 而非静默回退。

### 划分结果（`split.json`，fingerprint `e473498d…`）

| fold | test（留出动物） | val（留出 FOV，含两 session） | train |
|---|---|---|---|
| 0 | M1（4 卷） | M2 FOV I | M2 FOV II + M3（4 卷） |
| 1 | M2（4 卷） | M1 FOV II | M1 FOV I + M3（4 卷） |
| 2 | M3（2 卷） | M1 FOV II | M1 + M2（6 卷） |

标定（仅训练动物拟合）：fold0 offset 32727.5 / scale 13631.5（4 卷）；fold1 32037.75 / 13511.25（4 卷）；
fold2 32396.5 / 14603.33（6 卷）。

### Z 步长决策

ImageJ 头里的 spacing 在 5.0 / 7.0 / 15.0 之间自相矛盾，甚至同一 session 的血管与斑块通道给出不同值。
**以 README 的 5 µm 为准**（血管/斑块）、10 µm（神经元），所有不一致写进 `audit_report.md` 的警告区，
**不改数据、不静默取平均**——Z 步长直接决定深度分层的物理尺度。

### 审计中暴露并修复的缺陷

1. `content_fingerprint` 起初按文件字节算，漏掉「元数据不同、像素相同」的重复 → 改为像素指纹。
2. 重复组的 canonical 按路径字典序选，把 `3a Plaques` 选成"正本" → 改为按 identity score（是否带 mouse/fov/session 标签）排序。
3. 审计在肺数据上因 `no Z axis in axes='TYX'` 直接崩溃 → 拒绝是对的，但崩溃是错的：`z_span_um` 改为 try/except 记 0。
4. `3b - GFP neurons` 被误判为 262 页超栈 → 声明页数应与 `prod(shape[:-2])` 比较，而非只比 Z 轴。
5. manifest 存的是**相对数据根**的路径，`prepare` 却按 manifest 目录解析，导致全部跳过 → 补 `dataset_root` 与 `resolve_row_path`。

### 结论

数据可用但很小（10 卷、3 只鼠），**统计功效受限是结构性的**，bootstrap CI 只有 3 组时不可估（已用 `ci_estimable` 标注）。
泄漏边界已全部落成代码与测试：动物 / session / FOV / 通道 / 重复文件 / 时间轴六条轴各自有断言。
**本条目不含任何重建性能结论。**

### 后续动作

## SPUR-E001 — 无学习基线（A0 双线性 / A1 填零后 Wiener）

- **日期**：2026-10-28
- **阶段**：Phase 1（plan §6 参照基线）
- **目的**：在真实数据的三个留一鼠 fold 上建立下游一切学习方法的参照线，
  并**先证明「Wiener 不比插值好」这件事在本数据上的原因**，避免后面把插值器的上限当成方法的功劳。
- **配置**：`configs/base.yaml`，Y 方向行采样 `k=2`（测量比例 0.5），恒等 PSF，`context_depth=1`，
  `patch 512×512`（整幅），每折测试动物全部平面，共 782 个窗口/折。
- **命令**：`for f in 0 1 2; do for a in A0 A1; do python -m spur_mpm.evaluate --arm $a --fold $f --split test ...; done; done`
- **产物**：`runs/E001_{A0,A1}_fold{0,1,2}_test/`、`spur_mpm/experiments/E001_baselines/E001_table.md`

### 结果（测试动物，三折均值，括号内为跨动物 min–max）

| 指标 | A0 双线性 | A1 填零+Wiener |
|---|---|---|
| PSNR | 29.0616（27.60–30.42） | 29.0616（27.60–30.42） |
| SSIM | 0.7132（0.687–0.729） | 0.7132（0.687–0.729） |
| MAE | 0.0200（0.0172–0.0231） | 0.0200（0.0172–0.0231） |
| E_measured | 0.0000 | 0.0000 |
| E_missing | 0.0401（0.0343–0.0461） | 0.0401（0.0343–0.0461） |
| 血管 Dice | 0.8692（0.825–0.907） | 0.8692（0.825–0.907） |
| clDice | 0.8339（0.790–0.863） | 0.8339（0.790–0.863） |

**A0 与 A1 在全部三折上逐位相同（PSNR 到小数点后四位一致），这不是 bug，而是恒等 PSF 的必然结果。**
A1 的正则化解是 `argmin ||M_acq ⊙ (H x) − y||² + λ||x − x0||²`；当 `H = I` 时它在测量位置就是 `y` 本身，
在未测量位置退化为 `x0`（双线性插值）。也就是说**真实数据自带的点扩散函数让「反卷积」这一支失去意义**——
在没有额外 PSF 信息的前提下，Wiener 与插值是同一个算子。
已加测试 `test_the_two_baseline_arms_are_the_same_method_under_an_identity_psf` 锁住这一点，
并同时验证在非恒等 PSF（`sigma_xy_px=1.0, sigma_z_px=1.5`）下两臂确实分叉，说明代码路径本身是通的。
plan §6 第 405 行预警过这个局面（"Wiener 不比简单插值好 → 检查像域目标、正则化／边界／物理 PSF"），
现在的处置是：**保留插值作为先验，不伪造 PSF 优势**。

### 按深度分层（A0，band 200 µm，三折合计）

| 深度 (µm) | n | PSNR | Dice | clDice |
|---|---|---|---|---|
| 0–200 | 400 | 26.61 | 0.9085 | 0.8564 |
| 200–400 | 400 | 27.93 | 0.8625 | 0.8173 |
| 400–600 | 400 | 27.92 | 0.8551 | 0.8120 |
| 600–800 | 390 | 30.09 | 0.8661 | 0.8434 |
| 800–1000 | 266 | 32.38 | 0.8299 | 0.8156 |

**PSNR 随深度上升而血管 Dice 下降**：深层信号本身衰减，插值误差的绝对幅度随之变小（PSNR 好看），
但血管对比度不足让分割更容易断线（clDice 变差）。**结论：在本数据上 PSNR 不是深度层面的有效指标，
后续所有深度结论以血管 Dice/clDice 为准**，PSNR 只作为整体一致性检查。

### 需要注意的三件事

1. **E_measured = 0 是结构恒等式，不是性能**：插值器在测量位置原样返回 `y`。
   它的价值是回归测试——任何学习臂若 E_measured > 0，说明它把已经测到的体素改坏了。
2. **跨动物方差远大于方法差异的量级**：同一方法在三只鼠上的 PSNR 极差 2.8 dB、Dice 极差 0.08。
   只有 3 只动物，**任何小于约 1 dB / 0.03 Dice 的差异都不应被当作结论**；跨折只用范围表达，不报置信区间
   （`ci_estimable=false`，脚本已强制标注）。要主张方法优势，必须靠同一折内的配对比较。
3. 折间差异本身就是数据异质性：M2 作为测试动物时 PSNR 最低（27.60），与 M2 FOV I Session 2 只有 152 层有关。

### 结论

无学习基线在本数据上完全确定：**插值已是恒等 PSF 下的最优先验**，Dice 0.869 / clDice 0.834。
任何学习臂必须在**同一折内**显著超过这条线，否则只能说明它学到了插值。
A1 作为独立方法在本数据上不复存在，后续表格中与 A0 并列仅用于展示恒等性。

### 后续动作

1. SPUR-E002：有监督 S0/S1/S2（稠密参考作监督，用稠密验证集选模）。
2. SPUR-E003：自监督 MMS SS0/SS1/SS2（holdout 只用真实测量，选模只看 held-out 测量损失）。
3. 若要恢复 Wiener 的反卷积意义，需从数据估计 PSF（血管边缘的横向剖面）；已记录待决，不阻塞 E002/E003。

## SPUR-E003a — 自监督泄漏闸门（真实数据）

- **日期**：2026-10-28
- **阶段**：Phase 3 前置（plan §2.3「严格自监督口径」、SPUR-E003「防伪自监督」）
- **目的**：「零稠密标签」是一个需要被证明的断言，不是一句声明。在任何 SS 臂训练之前，
  先在**真实数据**上把这个断言变成可以失败的检查。
- **产物**：`spur_mpm/scripts/check_selfsup_leakage.py`、
  `spur_mpm/experiments/E003_selfsup/leakage_check.json`
- **覆盖面**：3 个 fold × (train/val/test 三种角色) = **30 卷**，每卷 3 个平面 × 3 个 holdout seed = **270 次探测**

### 三项检查

1. **盲性（主检查）**：定位 holdout 体素，把这些体素的**稠密像素替换为垃圾值**（`(x+0.37) mod 1`，保证与原值不同），
   其余一切不变，重建 item，要求网络输入**逐位相同**。臂能读到的所有信息都在 `inputs` 张量里
   （`y/mask/x0`，`U` 由 `y`、`mask` 推出），因此输入不变 = holdout 无路可达模型。
2. **正对照（让检查有可能失败）**：把**测量位置**（`M_in \ M_hold`）的体素同样替换为垃圾值，要求输入**必须改变**。
   没有这一项，第 1 项即使写成恒真也会"通过"。
3. **目标必须是测量**：holdout 目标必须等于该位置的实际采集值；不能是稠密参考（那等于有监督），
   不能是全零（那等于训练网络输出全黑）。同时校验 `M_in`、`M_hold` 恰好划分 `M_acq`。

### 结果

```
volumes checked: 30  planes/volume: 3
holdout share of M_acq: 0.500-0.500 (requested 0.5)
OK: holdout is blind on real data
```

270 次探测全部通过：输入对 holdout 完全不敏感、对测量位置敏感、目标全部是真实测量、划分比例精确 0.500。

### 闸门自身的测试（`spur_mpm/tests/test_leakage_harness.py`）

只证明「检查通过」不够，还要证明「检查会失败」。新增 3 个测试：

- 诚实构造 → 通过；
- 构造器把 `hold_target` 偷偷拼进 `inputs`（模拟真实泄漏）→ 检查**必须**报 `inputs changed`；
- 构造器把 holdout 目标置零 → 检查**必须**报 `all zero` / `not the acquired`。

### 结论

自监督路径在真实数据上的泄漏边界成立，且验证它的工具本身是可证伪的。
这不是性能结论，是口径结论：后续 SS 臂的「无标签」主张有这个工件支撑。

### 后续动作

1. E003b：SS0/SS1 训练，选模**只用** held-out 测量损失（验证 FOV 的 holdout，不读稠密参考）。
2. 冻结权重之后才允许 `evaluate.py` 读稠密参考，并在 run 目录留下 `select_metric=holdout_loss` 痕迹。

## SPUR-E000b — 逐层深度剖面（真实数据的可用性约束）

- **日期**：2026-10-28
- **阶段**：Phase 0 补全（plan §2.2 要求记录「Z 各层信号强度、背景、饱和像素、漂移」）
- **产物**：`spur_mpm/scripts/profile_depth.py`、
  `spur_mpm/experiments/E000_data_audit/depth_profile.{csv,json,md}`
- **方法**：对 10 卷全部平面（共 1866 层）逐层统计 mean / median / p99 / std / 精确零值比例 / 满量程比例，
  深度用 `z_step_um` 换算为物理 µm。

### 结果 1：没有数据缺陷

**全部 10 卷、1866 层的满量程（65535）像素比例为 0.00%**，也没有空白层。
这一条很关键：16-bit 上限若被触顶，标定 `offset+scale` 会把一段真实取值压到 1.0，
之后所有指标测的都是截断而不是方法。本数据不存在这个问题。

### 结果 2：每一卷都存在 >14% 的深度衰减（分析约束，不是缺陷）

| 卷 | 层数 | 首层 p99 → 末层 p99 | 比值 | 首层 mean → 末层 mean | 饱和 |
|---|---|---|---|---|---|
| M1_FOVI_S1 | 202 | 48303 → 34005 | 0.70 | 43411 → 32958 | 0.00% |

1. **深度分层必须报告，不能把整卷平均当作结论**：同一卷内 p99 相差 14–30%，

3. 直流偏置较大（背景 ~33000/65535），标定必须以分位数为准；用 min–max 会把噪声放大成"对比度"。

## SPUR-E002 — 有监督上界（S0 = Y+M，S1 = Y+M+X0）

- **日期**：2026-10-28
- **阶段**：Phase 2（plan §7 SPUR-E002「监督正向验证：S0/S1；同一数据／主干／Mask」）
- **目的**：在真实 3P 数据上建立**有标签上界**，并回答一个问题：
  「物理暖启动 X0 是否带来独立收益」。
- **配置**：`configs/experiments/E002_supervised_y_k2.yaml`；Y k=2；恒等 PSF；`context_slices=1`；
  patch 256 训练 / 512 评估；3000 步；batch 8；lr 2e-4（100 步 warmup + cosine）；
  L1 + 0.5·MS-SSIM；选模 = 稠密参考验证集 PSNR（有监督臂的口径）；
  与 E001 使用同一 `index.json` / `split.json`（哈希 `86a9659…`，三折 6 个 run 完全一致）。
- **产物**：`runs/E002_{S0,S1}_fold{0,1,2}{,_test}/`、
  `spur_mpm/experiments/E002_supervised/{E002_table.md,E001_vs_E002.md}`
- **评估**：`spur_mpm/experiments/eval_trained.sh`，冻结权重后才读稠密参考。

### 结果 1：有监督确实学到东西（S0 相对 A0，同折配对）

| 指标 | fold0 | fold1 | fold2 | 平均 Δ | 折数支持 |
|---|---|---|---|---|---|
| PSNR | +1.24 | +1.32 | +1.54 | **+1.37** | 3/3 |
| SSIM | +0.054 | +0.066 | +0.064 | +0.061 | 3/3 |
| MAE | −0.0012 | −0.0022 | −0.0021 | −0.0018 | 3/3 |
| 血管 Dice | +0.0176 | +0.0103 | +0.0153 | **+0.0144** | 3/3 |
| clDice | +0.0293 | +0.0209 | +0.0207 | **+0.0236** | 3/3 |

三只动物、三个方向上一致，且幅度（+1.37 dB / +0.014 Dice / +0.024 clDice）**高于**我们事先设定的
可分辨阈值（1 dB / 0.03 Dice 中的 Dice 项刚好接近阈值，clDice 明显超过）。
这是本项目第一个可主张的学习收益：**在恒等 PSF 下，插值不是上限，U-Net 类模型能稳定超过它约 1.4 dB**。

深度分层显示收益**在每一档都存在**，中段最大（200–800 µm 的 ΔDice 0.013–0.019），
最浅与最深两档最小（+0.008）。也就是说模型不是只改善了"好做的那一段"。

### 结果 2：X0（物理暖启动）没有独立收益

| 指标 | S0 平均 | S1 平均 | 平均 Δ | 折数支持 |
|---|---|---|---|---|
| PSNR | 30.4289 | 30.4567 | +0.028 | 3/3（但最大仅 +0.064） |
| 血管 Dice | 0.8835 | 0.8853 | +0.0017 | 2/3 |
| clDice | 0.8575 | 0.8585 | +0.0010 | 1/3 |
| E_measured | 0.0023 | 0.0022 | −0.0001 | 2/3 |

S1 与 S0 的差别**全部小于可分辨阈值**（最大 +0.064 dB、+0.005 Dice），clDice 甚至只在 1/3 折上更好。
原因与 E001 同源：**在恒等 PSF 下 X0 就是双线性插值**，而 `Y+M` 已经让卷积网络轻而易举地重建出它——
额外给一张插值图不增加信息。plan §4.3 把 X0 当作"物理先验"，本数据说明该先验在真实光学下是
**信息量为零的输入**。若要让 X0 有意义，必须先有一个数据驱动的 PSF（见待决项）。

### 结果 3：学习臂会轻微改写已测量体素

`E_measured`：A0/A1 = 0（构造上恒等），S0/S1 ≈ 0.0022–0.0026。
即模型用**测量位置上的极小误差**（0.23%）换取未测量区域的明显改善（`E_missing` 从 0.0401 降到 0.0342，−0.0059）。
这是真实存在的权衡，不是缺陷；在论文里必须与 E_missing 一起报告，否则"改善了重建"就掩盖了它同时也动了本来准确的数据。
`loss.dc_weight`（数据一致性）当前为 0，是 E005 消融的对象。

### 结论

1. **有监督上界成立且稳定**：S0 = PSNR 30.43 / Dice 0.8835 / clDice 0.8575，逐折 3/3 优于插值。
2. **X0 在本数据上无效**，与 E001 的 A0≡A1 是同一个物理事实的两次显现。
   后续把「X0 带来收益」当作卖点的写法必须删除或改为条件性陈述（需要真实 PSF）。
3. 学习臂的 E_measured > 0 必须显式报告。

### 后续动作

1. SPUR-E003b：SS0/SS1 自监督，选模只看 held-out 测量损失（E003a 的闸门已通过）。
2. SPUR-E004：S1 vs SS1 同折配对，回答「零标签代价多少」。
3. 待决：是否从数据估计 PSF（血管横向剖面），使 X0 与 A1 重新具备信息量。此项不阻塞 E003/E004。

## SPUR-E003b — 掩码测量自监督（SS0 / SS1）：**阴性结果**

- **日期**：2026-11-04
- **阶段**：Phase 3（plan §7 SPUR-E003 的自监督执行；E003a 闸门已通过）
- **目的**：在有监督上界（E002）已知的前提下，回答「不用稠密参考、只用掩码测量能否逼近上界」。
  具体是：SS0/SS1 能否**至少不劣于双线性插值**（A0）。
- **配置**：`configs/experiments/E003_selfsup_y_k2.yaml`；Y k=2；恒等 PSF；`context_slices=1`；
  patch 256 训练 / 512 评估；3000 步；batch 8；lr 2e-4；损失 = 自监督测量重建 + 0.5·MS-SSIM；
  `selfsupervision.ratio=0.5`（在**已测量**的行里再 hold out 一半作为训练目标，因此训练时输入只有 25% 的行有值）；
  `loss.dc_weight=0`；选模 = **仅** held-out 测量损失（不看稠密参考，`test_train_selection.py` 钉住）；
  与 E002 同一 `index.json` / `split.json`。
- **产物**：`runs/E003_{SS0,SS1}_fold{0,1,2}{,_test}/`、`spur_mpm/experiments/E003_selfsup/`、
  定性图 `spur_mpm/figures/qualitative/`（`qualitative_*` / `error_*` / `support_*` 三张一套）。

### 结果 1：自监督确实学到了东西（SS1 相对 SS0）

| 指标 | SS0 | SS1 | Δ |
|---|---|---|---|
| PSNR | 22.5099 | 24.2920 | **+1.78** |
| 血管 Dice | 0.5186 | 0.7536 | **+0.235** |
| clDice | 0.4204 | 0.6837 | **+0.263** |
| E_measured | 0.0676 | 0.0491 | −0.018 |
| E_missing | 0.0499 | 0.0561 | +0.006 |

X0（插值暖启动）在自监督下**第一次显出作用**（+1.78 dB、+0.235 Dice），
与 E002 中「X0 无收益」形成对照：有监督时网络从 `Y+M` 就能轻易重建插值图，无需额外喂进来；
自监督时输入信号弱得多，插值图成了一个真实可用的锚。

### 结果 2：但两个自监督臂都**远差于插值**（同折配对，3/3）

| 指标 | A0（插值） | SS0 | SS1 | SS1 − A0 |
|---|---|---|---|---|
| PSNR | 29.0616 | 22.5099 | 24.2920 | **−4.77** |
| 血管 Dice | 0.8692 | 0.5186 | 0.7536 | **−0.116** |
| clDice | 0.8339 | 0.4204 | 0.6837 | **−0.150** |
| E_missing | 0.0401 | 0.0499 | 0.0561 | +0.016 |

逐折 SS1−A0 的 PSNR：−5.66 / −2.82 / −5.82（3/3 劣于插值）。
SS1 仍比有监督上界低 6.16 dB、Dice 低 0.132。**当前形式的 MMS 不能替代稠密监督。**

### 结果 3（关键）：失效模式是**模型忽略输入**，不是"自监督没学到东西"

`E_measured` 是模型在**它被直接喂进去的测量体素**上的误差。A0 在该处误差**恒为 0**
（构造上插值等于测量值）。但：

- SS0 在给它的体素上误差 **0.063–0.074**（逐折 0.0631 / 0.0741 / 0.0655）；
- SS1 为 **0.043–0.057**（0.0565 / 0.0432 / 0.0477），仍然远大于 0。

也就是说模型**把自己拿到的真实测量改写掉了**，且改写幅度与它在缺失处的误差同量级
（SS1：E_measured 0.0491 vs E_missing 0.0561）。它没有在"补全"，而是在"重新生成一幅看起来像血管的图"。
这还解释了另一个怪现象：它在**缺失体素**上的误差（0.0561）与插值（0.0401）只差 0.016，
远没有 PSNR 的 4.77 dB 差距那么夸张——说明它丢分主要不是"缺失区补得差"，而是**把给它的测量也改坏了**。
SS0 → SS1 的改善主要来自"少犯错"，而非"更会用输入"（E_measured 仍 0.049）。

### 归因（为什么会这样）

恒等 PSF 下 `Y = M ⊙ X`，未测量体素的信息只存在于**空间先验**里，训练目标（holdout 测量）
与推理目标（补全）分布不同；而 `selfsupervision.ratio=0.5` 使**训练时**输入只有 25% 的 Y 行有测量
（`ky=2` 已丢掉一半，再 hold out 一半），而**评估时**给的是 50% 的行（`eval.input_support=full`），
模型因此学的是"在更稀的采样下内插"，而不是评估时那种"补一行空一行"的密度。
再叠加 `loss.dc_weight=0`（数据一致性项未启用），测量值对输出没有任何硬约束。

### 结论

1. **本阶段的自监督主张不成立**：SS1 比插值低 4.77 dB / 0.116 Dice，且 E_measured ≫ 0，
   不是一个有效的重建器。E004（S1 vs SS1 的"零标签代价"）**暂不进行**——在没有有效 SS 臂之前问
   "代价多少"没有意义。
2. 有监督上界（E002）依旧成立，是本阶段唯一可主张的学习收益。
3. 负结果本身有价值：它把问题定位到**两个可修的机制**（训练/评估采样密度不匹配、缺数据一致性），
   而不是"自监督不work"这种无法行动的说法。

### 后续动作

1. **SPUR-E005**（已启动，6 个 run 并行，GPU 0/1/3）：分别检验上述两个机制
   - `ratio010`：`selfsupervision.ratio=0.1`，使训练 holdout 密度 ≈ 评估采样密度；
   - `dc1`：`loss.dc_weight=1.0`，用 `y_in`/`in_mask` 施加数据一致性，压制 E_measured。
   两者若都不能把 `E_measured` 压到 ~0 且 PSNR 拉回 A0 以上，则 MMS 路线应被判定为不适用。
2. 定性核验图已产出（`spur_mpm/figures/qualitative/`）：含参考行、每臂 3 个 XY 层 + XZ/YZ + MIP-z、
   共享窗位的误差图、以及测量/缺失支持掩码图，供人工核对上述数值结论。

## SPUR-E005 — Mask／一致性消融：`ratio` 与 `dc_weight` 分开归因（计划 E005 的执行）

- **阶段**：Phase 3 收尾（E003b 的后续动作）
- **目的**：E003b 把 SS1 的失效定位到两个可修机制——(a) 训练/评估的测量密度不匹配，
  (b) `loss.dc_weight=0` 使测量值对输出毫无约束。本实验把两者**分开**测，使每个机制的效果可归因。
- **配置**：基线 = E003 的 SS1（Y `ky=2`/`kz=1`、X1 特征、`context_slices=1`、3000 步、batch 8），
  每次只改一个量：
  - `ratio010`：`selfsupervision.ratio` 0.5 → 0.1（训练时输入行占比 25% → 45%，靠近评估时的 50%）；
  - `dc1`：`loss.dc_weight` 0 → 1.0（用 `y_in`/`in_mask` 直接惩罚与给定测量的分歧）。
  6 个 run（2 变体 × 3 折），GPU 0/1/3 并行；选模口径与 E003 相同（**仅** held-out 测量损失，不碰稠密参考）。
- **产物**：`runs/E005_{ratio010,dc1}_fold{0,1,2}{,_test}/`、`spur_mpm/experiments/run_e005.sh`。

### 结果 1：三折均值（`eval.input_support=full`，与 E001/E002/E003b 同口径）

| arm | PSNR | SSIM | MAE | Dice | clDice | E_measured | E_missing |
|---|---|---|---|---|---|---|---|
| A0（插值） | 29.0616 | 0.7132 | 0.0200 | 0.8692 | 0.8339 | **0.0000** | 0.0401 |
| S1（监督上界） | 30.4567 | 0.7758 | 0.0182 | 0.8853 | 0.8585 | 0.0022 | 0.0341 |
| SS1（E003 原配方） | 24.2920 | 0.4038 | 0.0526 | 0.7536 | 0.6837 | **0.0491** | 0.0561 |
| E005 `ratio010` | 23.5165 | 0.3821 | 0.0587 | 0.7325 | 0.6227 | **0.0626** | 0.0549 |
| E005 `dc1` | 28.4392 | 0.7109 | 0.0239 | 0.8440 | 0.7960 | **0.0022** | 0.0456 |

### 结果 2：`dc1` 修的正是「改写测量」这一症状

`E_measured` 0.0491 → **0.0022**，三折分别 0.0026 / 0.0023 / 0.0018，与两个**有监督**臂
（0.0014–0.0026）已经同一量级；PSNR +4.15 dB（三折 **+4.28 / +1.82 / +6.34**，同向），
Dice +0.090。注意本次评估 `eval.consistency_projection=none`，**没有任何评估期的硬投影**——
这 0.0022 是模型自己学出来"不要动给我的体素"，而不是被评估代码蒙掉的。
这直接确认了 E003b 的归因 (b)：SS1 的损失主要来自破坏输入，而不是补不出来。

### 结果 3：`ratio010` 在 test 上无效甚至有害，且**证伪了选模口径**

| fold | holdout loss（SS1 → ratio010） | test PSNR（SS1 → ratio010） | E_measured |
|---|---|---|---|
| 0 | 0.03980 → **0.03819** | 23.4956 → 21.5742（−1.92 dB） | 0.0565 → 0.0802 |
| 1 | 0.04361 → **0.04044** | 24.7786 → 24.2664（−0.51 dB） | 0.0432 → 0.0511 |
| 2 | 0.04056 → **0.03757** | 24.6019 → 24.7089（+0.11 dB） | 0.0477 → 0.0564 |

**holdout loss 三折一致变好，而 test 指标两折变差、一折持平、`E_measured` 三折一致变差。**
因此：

1. 归因 (a) 不成立——提高训练时的测量密度并没有让模型更会在评估密度下重建；
2. 更重要的方法学结论：**held-out 测量损失不能作为自监督臂的选模信号**。它奖励的是
   "在训练密度下内插"，而这恰恰是我们不想要的行为。E003/E005 的 `best.pt` 都是按它选的，
   意味着**这两批的自监督臂可能都没选到最好的一步**；后续必须先解决选模信号再谈对比。

**这个担心被量化了（补查）**：逐 run 比较 `best.pt` 与 `last.pt` 的权重，12 个自监督 run 里
**只有 `E003_SS1_fold1` 一个**两者不同，其余 11 个逐位相同（`E005_dc1` 三折全部相同）。
也就是说 E005 的 `best.pt` 事实上就是最后一步，用 `last.pt` 复评（`runs/E005_dc1_*_test_last`）
与 `best.pt` 结果**完全一致**。选模信号的问题依然存在于"若训练更久会怎样"，但**不构成对
上述 `dc1` 数值的折扣**。

### 结果 4：`dc1` 与插值在噪声门限内不可区分，但缺失行确实更差

> **更正（SPUR-E010 时发现）**：本节初版把 `dc1 − S1` 那一列的数字错填进了 `dc1 − A0` 列，
> 因而得出"低 2.02 dB / 0.046 Dice、三折同向"的结论。`2.02 dB` 是 `dc1` 相对 **S1** 的差距，
> 不是相对 A0 的。下表与结论均已按 `runs/*_test/summary.json` 重新核对。

| fold | `dc1` − A0（PSNR / Dice） | `dc1` − S1 | `dc1` − SS1 |
|---|---|---|---|
| 0 | −1.38 dB / −0.0375 | −2.69 dB / −0.060 | +4.28 dB |
| 1 | −1.01 dB / −0.0386 | −2.32 dB / −0.049 | +1.82 dB |
| 2 | **+0.52 dB / +0.0007** | −1.04 dB / −0.015 | +6.34 dB |
| 均值 | **−0.62 dB / −0.025** | −2.02 dB / −0.041 | +4.15 dB |

三折均值 `dc1` 比 A0 低 **0.62 dB / 0.025 Dice**，两项都**低于**「1 dB / 0.03 Dice」的
可主张门限，且 fold 2 为正——所以正确表述是 `ky=2` 这个密度下 **`dc1` 与插值在噪声内不可区分**，
既不能说它更差，也不能说更好。（初版"超过半倍跨动物方差"的说法随之作废：0.62 dB 只占
2.8 dB 的 22%。）

与 S1 的差距则是扎实的：−2.02 dB / −0.041 Dice，三折同向，**有监督上界仍明显更高**。

机制上有两点分别成立：

1. `dc1` 的 `E_measured≈0`（0.0022）——但这是 `torch.where(given, y_in, pred)` 的**构造性质**，
   不是学出来的，不能当作优点主张。
2. `E_missing` = 0.0456 > A0 的 0.0401，逐折 +0.0085/+0.0082/−0.0003（`ky=4` 上
   +0.0079/+0.0027/+0.0051）。方向在 6 个"折×密度"里 5 个一致，但 `E_missing`
   没有标定过的噪声门限，只能说**有方向性证据表明先验补缺失行不如双线性**，
   不足以单独立为结论。这不是配方问题，是当前几何下先验没有胜过插值这个强基线。

### 结论

1. 按 E003b **预注册**的判据（`E_measured≈0` 且 PSNR > A0），`dc1` 只满足一半 ⇒
   在 `ky=2` 这个采样几何下，**MMS 路线判为不适用**，不写进主结论。
2. `dc1` 的价值是**诊断性**的：它把"改写测量"和"补不好缺失"两个失效模式分离开，
   使"先验弱于插值"成为唯一剩下的解释。
3. 选模口径需要先修（见结果 3 第 2 条），否则后续任何自监督对比都建立在未选中最好一步的权重上。

### 后续动作

1. **SPUR-E009**（已启动，9 个 run，两波，GPU 0/1/2）：把采样几何换成 `ky=4`（3 行缺失夹 1 行测量），
   在插值明显变弱的设定下重比 A0 / S1 / SS1 / SS1+`dc1`。
   **注意**：E009 只能回答"几何依赖"，不能用来复活 `ky=2` 上的 MMS 主张。
2. 选模信号：下一步需引入不依赖稠密参考、且与评估口径一致的代理（候选：与评估同密度的
   holdout 损失 + 固定步数早停），并在 E009 上先验证它与 test 指标的相关性，再用于选模。
3. 定性核验图：`spur_mpm/figures/qualitative/` 已有 fold 0/1/2 五臂图（A0/S0/S1/SS0/SS1）；
   `dc1` 臂已补（`*_with_dc1.png`）。

## SPUR-E009 — 采样几何换成 `ky=4`：MMS 的结论是否依赖几何？

- **阶段**：Phase 3 判据复核（E005 后续动作 1）
- **目的**：E005 在 `ky=2`（隔一行测一行）上判 MMS 不适用。一个自然的反驳是"50% 的行太容易，
  插值本身就是强基线"。本实验把采样降到 `ky=4`（每 4 行测 1 行，25%），在插值明显变弱的设定下重比。
- **配置**：`spur_mpm/configs/experiments/E009_sampling_y_k4.yaml`，`sampling: {mode: y, ky: 4, kz: 1}`，
  `selfsupervision: {ratio: 0.5, geometry: row}`（训练时只看到测量行的 50%，即全体的 12.5%），
  其余与 E003/E005 完全一致（X1 特征、`context_slices=1`、3000 步、batch 8、`l1=1.0`+`ms_ssim=0.5`）。
  9 个 run：A0（**重新在 `ky=4` 上算插值基线**，不能引用 `ky=2` 的 29.06 dB）、S1、SS1、SS1+`dc_weight=1.0`，各 3 折。
- **产物**：`runs/E009_{A0,S1,SS1,SS1dc1}_fold{0,1,2}{,_test}/`、`run_e009.sh`、`eval_e009.sh`、`run_post_e009.sh`。

### 结果 1：三折均值（`eval.input_support=full`）

| arm | PSNR | SSIM | MAE | Dice | clDice | E_measured | E_missing |
|---|---|---|---|---|---|---|---|
| A0（插值，`ky=4`） | 27.0708 | 0.5436 | 0.0307 | 0.8076 | 0.7548 | **0.0000** | 0.0410 |
| S1（监督上界） | 28.4921 | 0.6281 | 0.0272 | 0.8357 | 0.8152 | 0.0043 | 0.0348 |
| SS1 | 21.8958 | 0.1961 | 0.0659 | 0.6640 | 0.5828 | **0.1050** | 0.0529 |
| SS1 + `dc1` | 26.2256 | 0.5270 | 0.0352 | 0.7971 | 0.7432 | **0.0020** | 0.0462 |

### 结果 2：稀疏化削弱了插值，但没有把 `dc1` 从"平手"推向"落后"或"领先"

| 量 | `ky=2` | `ky=4` | 变化 |
|---|---|---|---|
| A0（插值） | 29.0616 dB | 27.0708 dB | **−1.99 dB** |
| S1（监督） | 30.4567 dB | 28.4921 dB | −1.96 dB |
| `dc1` | 28.4392 dB | 26.2256 dB | −2.21 dB |
| SS1 | 24.2920 dB | 21.8958 dB | −2.40 dB |
| `dc1` − A0 | **−0.62 dB** | **−0.85 dB** | 差距略微拉大 0.23 dB |

> **更正**：初版此处写 `ky=2` 的 `dc1 − A0` 为 −2.02 dB，并据此说"差距缩小 1.17 dB"。
> −2.02 dB 是 `dc1 − S1`（见 E005 结果 4 的更正）；对 A0 的差距是 **−0.62 dB**。
> 因此变化方向反了：`ky=2 → ky=4` 的差距是从 −0.62 **扩大到** −0.85，拉大 0.23 dB。

插值按预期掉到 27.07 dB（−1.99 dB），`dc1` 掉得更多（−2.21 dB），所以两者距离略微拉大。但：

1. **两个密度下的差距都低于 1 dB 门限**（−0.62 / −0.85 dB），按项目规则**两个都不能主张**；
   正确的说法是 `dc1` 在两个密度下都与插值**在噪声内不可区分**，而不是"落后插值"；
2. `ky=4` 上三折分别为 −1.39 / −0.31 / −0.83 dB，同向为负；但 `ky=2` 上三折是
   −1.38 / −1.01 / **+0.52**，并非同向，所以"三折同向"只在 `ky=4` 成立；
3. 拉大 0.23 dB 远小于噪声底，**不能**说"稀疏化让 `dc1` 相对变差"；
4. SS1（无 `dc1`）在 `ky=4` 上更差（−5.17 dB，`E_measured` 0.0491 → **0.1050**）：
   采样越稀，模型覆盖输入的倾向越强。这与 E003b 的失效模式一致，说明它**随缺失比例单调放大**，
   而不是 `ky=2` 特有的偶然。这一条不受上面的更正影响。

### 结果 3：连通域计数给出定性与定量之间的一致图像（fold 0 展示裁剪）

`pred_fraction` / `n_components` 来自评估脚本对二值血管的连通域统计（真值 `n_components≈46.9`）：

| arm | `ky=2` 连通域 | `ky=4` 连通域 |
|---|---|---|
| 真值（稠密） | 46.9 | 46.9 |
| A0（插值） | 31.7 | 25.0 |
| S1（监督） | 34.8 | 28.0 |
| `dc1` | 42.2 | 31.7 |
| SS1 | **9.1** | **7.0** |

SS1 的血管数掉到真值的 1/5，正好对应 E003b 说的"模型忽略输入、把结构糊平"。
`dc1` 把连通域数拉回到接近 S1 的水平——**这是 `dc1` 唯一真正修好的东西**，
但 PSNR 仍未翻正，说明修好的是"拓扑别塌"，没修好"缺失行填得准"。

### 结论

1. 按 E005 预注册的判据，`ky=4` 上 `dc1` 仍未同时满足「`E_measured≈0` 且 PSNR > A0」
   ⇒ **MMS 路线在两个采样密度下都不适用于当时的判据**，主结论不含 MMS。
2. E009 只回答「几何依赖」，**不能用来复活 `ky=2` 上的主张**；它给出的信息是：
   `dc1` 相对插值的差距（−0.62 → −0.85 dB）在两种几何下都**低于 1 dB 噪声门限**，
   且**没有随稀疏化改善**（略微拉大 0.23 dB，同样在噪声内）。
   （初版此处写"差距随稀疏化单调收窄"，与结果 2 的更正冲突，已改。）
3. 剩下的问题不是"采样多稀"，而是"先验没学到插值所学的那件事"（`E_missing` 三折均劣于 A0：
   0.0462 vs 0.0410）。继续加密或稀释采样都不解决这个。

### 后续动作

1. 采样几何不再作为变量；若还要在 MMS 上推进，必须先有**与评估口径一致的选模信号**
   （E005 结果 3 已证伪 held-out 测量损失）。
2. 若放弃 MMS，则主线转向「有监督 + 物理先验」（S1 在两种几何下都稳定领先 A0 约 1.4 dB，
   是本项目目前唯一可复现的正收益方向）。
3. 定性图：`spur_mpm/figures/qualitative/*_with_dc1.png`（`ky=2`）与 `*_ky4.png`（`ky=4`），
   行序 = 稀疏输入（蓝 = 未测） / 密集真值 / 各消融臂。

## SPUR-E010 — 同输入口径复核（`input_support=holdout`）：MMS 的收益到底在哪一层？

- **阶段**：Phase 3 二次评估（口径复核，不是新训练）
- **目的**：E005 / E009 的头条口径是 `eval.input_support=full`——A0、S1、SS1、`dc1` 都拿到
  **全部**测量行（`ky=2` 时 50%，`ky=4` 时 25%）。但 MMS 的训练输入只有测量行的一半
  （见 `spur_mpm/ssl/holdout.py` 的 `split_holdout`，`ratio=0.5`）。也就是说：
  头条比较里，`dc1` 是在"训练只见过一半行"的条件下，去跟"评估时看满全部行"的 A0 比。
  本实验把评估输入也降到同一半，做**同输入**比较；同时，被扣下的那半行是**真实含噪测量**，
  可以直接检验"物理一致性"学到的东西有没有迁移到真实测到的体素上。
- **新增开关**：`eval.holdout_baselines`（`spur_mpm/evaluate.py: withholds_at_eval`，默认 `false`）。
  语义：`input_support=holdout` 默认只对 `supervision=="self"` 的臂扣行；打开该开关后
  **非自监督臂（A0/S1）也一起扣**，才能做到同输入。
  `full` 口径下该开关恒不生效，防止二次口径漏进头条表。
- **产物**：`runs_holdout/E000_A0heldout_fold{0,1,2}_test/`（A0 + 开关）、
  `runs_holdout/E003_SS{0,1}_fold*_test/`、`runs_holdout/E005_dc1_fold{0,1,2}_test/`，
  脚本 `spur_mpm/experiments/eval_variants.sh`；单测 `spur_mpm/tests/test_train_selection.py`。
  采样 `y_k2`，`consistency_projection=none`（关掉硬投影，让差异只来自模型本身）。

### 结果 0（必须先修的坑）：早期 A0-holdout 数字是无效的

`withholds_at_eval` 初版只对 `supervision=="self"` 扣行。A0 的 `supervision` 是 `none`，
于是带 `input_support=holdout` 跑 A0 时它**静默拿到了满输入**，产出
`runs_holdout/E000_A0_fold0_test` = **29.1583 dB / `E_measured` 0.0000**。
这个数比 `full` 口径的 A0（29.0616 dB）还高，物理上不可能，是口径 bug 的直接证据。
该目录已删除；正确数字是下表的 `A0h`（26.4493 dB，`E_measured` 0.02197）。

### 结果 1：同输入口径的三折均值（`ky=2`，`input_support=holdout`）

| arm | PSNR | SSIM | Dice | clDice | `E_measured` | `E_missing` | `E_hold` |
|---|---|---|---|---|---|---|---|
| A0h（插值，**也扣行**） | 26.6418 | 0.5342 | 0.7953 | 0.7435 | 0.0212 | 0.0427 | 0.0423 |
| SS0（`E003_SS0`，仅 fold 0） | 21.5639 | 0.1672 | 0.4975 | 0.4126 | 0.0601 | 0.0655 | 0.0392 |
| SS1 | 24.7550 | 0.3522 | 0.7456 | 0.6732 | 0.0460 | 0.0464 | 0.0365 |
| SS1 + `dc1` | **26.8066** | **0.5537** | 0.7928 | 0.7492 | **0.0197** | 0.0437 | 0.0371 |

同折配对差值（3 折逐折 → 均值）：

| 对比 | 指标 | fold0 | fold1 | fold2 | 均值 | 判读 |
|---|---|---|---|---|---|---|
| `dc1` − A0h | PSNR | −0.2444 | +0.2079 | +0.5310 | **+0.1648** | 远低于 1 dB ⇒ **平手** |
| `dc1` − A0h | Dice | −0.0034 | −0.0067 | +0.0025 | **−0.0025** | 远低于 0.03 ⇒ **平手** |
| `dc1` − SS1 | PSNR | +2.2816 | +0.8126 | +3.0607 | **+2.0516** | 3/3 为正 |
| `dc1` − SS1 | Dice | +0.0671 | +0.0241 | +0.0504 | +0.0472 | 3/3 为正 |

### 结果 2：`dc1` 相对插值的优势**不随口径改变**——一直是"不可区分"

`full` 口径 `dc1 − A0` = −0.62 dB，同输入口径 `dc1 − A0h` = **+0.16 dB**。
符号翻转，但两个数的绝对值都远小于 1 dB 门限，所以正确的表述是
**两种口径下都无法区分**，而不是"同输入后翻正了"。任何"同输入之后 MMS 就赢了"的说法
都是把 +0.16 dB 当成信号，按项目规则不允许。

### 结果 3：`dc1` 相对 SS1 的 +2.05 dB，来源是**硬投影 + 一致性项**，不是架构

`dc1` 与 SS1 是同一个臂，只差 `dc_weight=1.0`。所以这 +2.05 dB 全部来自
「训练期在扣下行上算一致性」这**一个**改动。E009 结果 2 的第 4 条已经说明：
SS1 的失效模式是"覆盖输入"，`ky` 越大越严重（`E_measured` 0.0491 → 0.1050）。
`dc1` 把 `E_measured` 从 0.0460 压到 0.0197，是把"别覆盖实测量"这件事修掉了。
**这是本项目目前唯一可复现、且机制清楚的正收益**——但它的参照系是 SS1，不是插值。

### 结果 4（关键，新信号）：`dc1` 在被扣下行上确实比插值准，3/3 动物、~93–100% 窗口

`E_hold` 只统计"评估时被扣下的那半测量行"，它们**是真实含噪测量**，折叠外动物，
训练时从未见过（训练期的扣行来自训练卷，评估期来自测试卷，无跨动物泄漏）。

| 对比 | fold0 | fold1 | fold2 | 均值 | 逐窗口 `dc1` 更优 |
|---|---|---|---|---|---|
| `E_hold`：A0h | 0.0439 | 0.0487 | 0.0344 | 0.0423 | — |
| `E_hold`：SS1 | 0.0383 | 0.0416 | 0.0296 | 0.0365 | — |
| `E_hold`：`dc1` | 0.0392 | 0.0422 | 0.0300 | 0.0371 | — |
| `dc1` − A0h | **−0.0048** | **−0.0065** | **−0.0044** | **−0.0052**（相对 −12%） | 725/782、758/758、319/326（92.7% / 100% / 97.9%） |
| `dc1` − SS1 | +0.0009 | +0.0006 | +0.0004 | +0.0006 | 12/782、6/758、3/326（1.5% / 0.8% / 0.9%） |

读法：
1. 三只动物上 `E_hold` 的差值全部为负，逐窗口也几乎全为负（92.7% / 100% / 97.9%），
   而 `dc1` 相对 SS1 则几乎全为正——**方向完全可分**，这不是噪声抖动；
2. 但 `E_hold` **没有标定的噪声底**（不像 PSNR 有 1 dB、Dice 有 0.03）。
   所以只能说"方向一致、量级 −12%、3/3 动物同向"，**不能**说"显著改善"；
   要主张它，下一步须按 E001 的做法给 `E_hold` 标一个跨动物噪声底；
3. 逐窗口统计会**高估**显著性（测试窗口大面积重叠），只作描述性证据，不作推断；
4. 这一层收益**没有**传导到 PSNR/Dice：差值被搬到了 `E_missing`
   （A0h 0.0427 vs `dc1` 0.0437，`dc1` 略差）。即
   `dc1` 学会了"在扣下的真实行上贴得更紧"，但没有因此把**从未测过的行**填得更准。
   这与结果 2 的"平手"完全自洽，也再次指向同一个瓶颈：
   **先验没学到插值所学的那件事**。

### 结论

1. 头条结论不变：**稀疏重建上与插值在噪声门限内不可区分**，无论 `input_support=full`
   还是同输入的 `holdout`。MMS 不能作为主线的性能主张。
2. 但 MMS 的失效机制已经被精确定位并部分修复：SS1 → `dc1` 的 +2.05 dB
   全部来自"训练期在扣下行上做一致性"，其作用是**阻止模型覆盖真实测量**，
   而不是"补全得更好"。
3. 新出现的正信号是 `E_hold`（−12%，3/3 动物、>92% 窗口）：
   在**真实含噪、从未参与训练**的那些行上，`dc1` 确实比插值逼近得更好。
   这条如果标定了噪声底，就是本项目第二个可主张的结果，且它是"物理一致性"
   最直接的对症证据。
4. `E_measured` / `E_missing` / `E_hold` 三个量目前**都没有标定噪声底**，
   因此本节所有提及它们的比较一律按"方向性/描述性"处理。

### 后续动作

1. 给 `E_hold` / `E_missing` 标跨动物噪声底（复用 E001 的 bootstrap + leave-one-animal-out），
   标定后本条要么升级为可主张结论，要么按规则撤回。
2. 若 `E_hold` 通过标定，主线叙述调整为：
   "自监督 MMS 的收益在**已测但被扣下的行**上（保真度），不在**未测行**的补全上"，
   并把"未测行补全"交给「有监督 + 物理先验」（S1）。
3. `spur_mpm/experiments/eval_variants.sh` 需要在 `input_support=holdout` 且臂为非自监督时
   自动带 `--set eval.holdout_baselines=true`，否则会重犯结果 0 的错。
4. 定性图元数据：M1/M2 那两张 `_with_dc1/_ky4` 图早于 sidecar 记录 `sampling` 字段的改动，
   图上 `sampling` 显示为空；图本身正确，仅元数据缺失，重画可补齐。

## SPUR-E010a — 定性图重制：把"没测到"画成"没测到"，把灰度换成伪彩

- **日期**：2026-10-29
- **目的**：核验方指出两件事：(1) `qualitative_*.png` 第 1 行"密集参考"看起来和 Input 行
  一模一样；(2) 全图是灰度、对比弱，要求改成 paper 级伪彩，指标写在每个子图内部右下角，
  行列注释只留方法关键词。

### 对 (1) 的核查：不是数据错，是取景错

直接把 dump 的掩码当数据核对（`qualitative_M1_FOVII_S1_vessels.npz`，尺寸 202×256×256）：

| 取景 | 实测占比 | 说明 |
|---|---|---|
| `XZ (y=mid)`，旧的第 4 列 | **1.000** | y=128 是一整行**全测**的 y 行 |
| `YZ (x=mid)` | 0.500 | |
| `MIP-z` | 0.500 | |
| 旧图里 1.0 这一列 | — | 输入行与真值行**本来就该是同一张图** |

根因是**两级稀疏的结构**：采集掩码只在 y 上跳行（`M(z,y,x)=[(y-p_y) mod k_y==0]`），
x 与 z **从不**欠采样。因此任何一张 XZ 平面要么整张全测、要么整张全缺，只取决于它切在
哪一行 y。旧图固定切 `y=H//2`，恰好切在一整行全测的 y 上——于是第 4 列左格（输入）与
左格下方的真值格在数值上几乎完全相同，肉眼只能得出"GT 和 Input 一样"的结论。

第二个因素是分辨率：150 dpi 下 256 行只占约 1.76 px，旧版 50% 占空比的深蓝条纹被平均成
"整体变暗"，于是"空一半"和"暗一点"看起来是同一件事。

真值本身没有被动过：`_make_item` 里 `target = dense[center]`，是不经任何掩码的密集体数据。

### 对 (2) 的改动：新的图规格

1. **列集合**（`VIEW_KEYS`，8 列）：`XY 25% / XY 50% / XY 75% / XZ given / XZ gap /
   YZ mid / MIP-z / Zoom`。关键是把 XZ 拆成两列：
   `XZ given` 取覆盖最好的 y 行（平手时取靠近中间者），`XZ gap` 取覆盖最差的 y 行。
   后者才是"一个方法在没有任何测量处凭空造了什么"的那一格。
2. **未测体素涂 `#22d3ee`（亮青）**，magma 色表任何一点都到不了该颜色，且
   `interpolation="nearest"` 保留满强度条纹，任何 dpi 下都不会糊成平均色。
   配合 `cmap.set_bad`，NaN 即是青色，不可能是"暗的血管"。
3. **每列一个显示窗**（取密集参考的 p0.5–p99.5，全列共用）。若每个子图各自归一化，
   一个偏暗的预测会被拉成"看起来正常"，这本身就是一种误导。
4. **指标写进子图右下角**：`_panel_metrics` 只统计"屏幕上这一格"的像素，PSNR 与 Dice
   都是该子图与其对应的参考裁片之间算出来的，读者不必再把图上数字与表格对上。
   Input 行写 `meas NN%`（该子图的实测体素比例），全 NaN 的格子写 `meas 0% (no data)`。
5. **行列注释只留关键词**：左行竖排 `Input / GT / S0 / S1 / SS0 / SS1 / dc1`，
   上行列名短词，整图底部一行 6.2pt 灰字交代渲染参数（色表、窗口、采样、投影、
   `XZ given/gap` 切在哪一行 y、Zoom 裁在何处）。
6. **Zoom 列**：中位 z 平面上 96×96 裁片，锚点用 `uniform_filter` 平滑后的方差峰值，
   **对全图只算一次**，保证各行裁的是同一块；这样一行 y 占约 5 px，条纹可辨。
7. 其余三张图跟随同一套配色：`error_*` 用 inferno + 全行共用上限，
   `support_*` 标注"白=已测，x/z 从不欠采样，点阵全在 y 上"，`profile_*` 保留沿 y 的
   强度剖面（测到的行画青色点）。

## SPUR-E013 — MPM-3P-SQH 新数据审读：它是什么，能验证什么，不能验证什么

数据：`/ssd1/wjb/Data/MPM-3P-SQH/`（3 个 TIFF）。分析脚本
`spur_mpm/scripts/inspect_sqh.py`，图在 `spur_mpm/figures/sqh/`，
全部数字在 `spur_mpm/figures/sqh/sqh_stats.json`。

### 1. 结构：三段互不相同的 2-D 延时影像，没有 z

| 文件 | 尺寸 | 帧数 | SHA-256 头 | 说明 |
|---|---|---|---|---|
| `CellVideo 1(128 128).tif` | 128×128 | 5000 | `9489f88e…` | uint16 单通道；**2026-10-29 22:53 重新上传** |
| `CellVideo 1(256 256).tif` | 256×256 | 3191 | `cf4395c4…` | uint16 单通道 |
| `CellVideo 1(512 512).tif` | 512×512 | 800 | `4d6d7187…` | uint16 单通道 |

> **更正**：初次上传时 `128` 文件与 `256` 文件逐字节相同（SHA-256 `91aa735d…`），
> 我在 22:45 的 E013 初稿里据此判它是重复文件。用户已于 22:53 重新上传；
> 现在它是独立的 5000 帧采集。下面的数字全部按新文件重算。

三段都不是彼此的降采样或裁剪：两两时间均值的互相关在试过的所有缩放/裁剪下
|r| ≤ 0.27（128 vs 256 中心 1:1 仅 0.196，128 vs 512 ×0.25 最高 0.274，
其余为 0.08–0.16，部分为负）。所以是三次独立采集，不是同一视场。

轴序 **TYX**。元数据只有 `PageNumber` 和 `resolution 88` —— 88 px/cm 换算成
113 µm/px，对"cell video"显然不合理，判为采集软件的占位标签，**不据此建立物理尺度**。
方向与相位信息全部缺失。

### 2. 信息量：极低光子计数 MPM，噪声是乘性的

对每个像素做光子传递拟合 `var = G·(mean − offset)`（背景段 R² 0.986 / 0.903 / …）：

| 量 | 128 视频 | 256 视频 | 512 视频 | Dryad（对照，MID z 层） |
|---|---|---|---|---|
| 直流台阶 offset | 9040 counts | 8895 | 6145 | ≈33000–34500 |
| 每光子计数 G | 4134 counts/photon | 6398 | 7234 | — |
| 每像素每帧光子数 | **0.561** | 0.165 | 0.213 | — |
| 单帧噪声 σ | ≈2830 counts | ≈2300 | ≈3400 | 500–600 |
| σ / 台阶 | **31 %** | 26 % | 45 % | **1.6 %** |
| 结构尺度（自相关半宽） | 7 px | 11 px | 78 px | — |
| 两半栈平滑均值互相关 | **0.959** | 0.757 | 0.773 | — |
| 单帧 vs 全长均值相关（σ=1 平滑） | **0.72** | 0.50 | 0.05 | — |

即：三段单帧的**相对噪声都比 Dryad 高 15–28 倍**，并且彼此差一个量级：
128 视频最亮最稳（0.56 光子/像素/帧，漂 1.2 %，两半栈相关 0.96），512 视频最差
（单帧与均值几乎无关）。**128 是这批数据里唯一可以直接做定量实验的一段**。

单像素帧间相关（256 视频）只有 0.23；σ=4 平滑后 0.71，σ=8 到 0.83；
128 视频 σ=4 后已达 **0.978** —— **低相关是噪声造成的，不是结构在动**。

其他读数：
- 逐帧均值：256 从 10810 线性漂到 9077（**−12.3 %**），128 只漂 **−1.2 %**，
  512 漂 +0.7 %；台阶与增益在此期间不变 → 漂的是信号（漂白或对焦），不是探测器。
- 照明不均匀：256 行均值 10155→9226、列 9424→9935（≤10 %）；512 列向梯度更大
  （6466→8452），左边缘有暗带。
- 三段都无坏点、无饱和、无零值帧。
- 512 视频：单帧与均值相关仅 0.05；100 帧分块均值的互相关 0.86→0.62，块匹配平移
  只有 2–24 px 且对相关几乎无改善 → 场景在缓慢变化，不是刚体漂移。

### 3. 噪声模型可预测，因而误差棒可以在此被检验

取前 1000 帧均值作参考：

| 视频 | 残差 σ 实测 | 光子模型预测 | z=(frame−ref)/σ̂ 的 s.d. | \|z\|>3 |
|---|---|---|---|---|
| 128，第 1000 / 2000 / 4000 / 4999 帧 | 3591 / 3133 / 3526 / 3594 | 2918 | **1.09 / 0.99 / 1.10 / 1.07** | 1.6–2.5 % |
| 256，第 1000 / 2000 / 3000 帧 | 3083 / 2347 / 2617 | 2343 | 1.15 / 0.89 / 0.96 | 1.9–4.0 % |

**预测误差约 10 %**，且跨帧方向一致（不是偶然拟合）——那 10 % 主要是参考本身
跨了整段影像、含缓慢漂移。`|z|>3` 只占 2 %，说明尾部也没有失控。

这一点直接补上当前最大的空缺：`E_measured / E_missing / E_hold` 一直没有标定基线，
只能作描述性比较。这批数据给出的是"每个像素都有已知方差的重复测量"，可以
把不确定性头按标准的 calibration / reliability 曲线来打分。

### 4. 能用来验证什么，不能验证什么

**不能**：Z 方向的一切。没有 z 轴，所以 3-D 稀疏重建、k 行采集的 z 插值、
各向异性 PSF、`E_hold` 都不能在这里评估；也不能进 3-D loader（轴纪律：TYX 属 Phase 6）。
分辨率标签不可信 → 不能比 PSF 尺寸。

**能**（按价值排序）：

1. **不确定性/误差棒的校准台（最高价值）**。长期均值 = 近乎无噪参考，单帧 = 一次真实
   测量，二者之差就是逐像素真值误差，且方差已知。得到的是可重复、逐像素、
   不依赖跨动物方差地板的误差棒评测（现规则：跨动物 2.8 dB / 0.08 Dice，1 dB / 0.03 Dice
   以下不得声称）。
2. **2-D 版本的同一算子压力测试**：把同一套行掩码（ky=2 / 4）加到高信噪参考上，
   再加真实帧噪声，检验 Wiener / 物理先验分支**换显微系统、换样本、换噪声水平后是否还成立**。
   必须标成"2-D，无 z"，不得混进 3-D 表格。
3. **用测量到的噪声模型给 Dryad 合成真实散粒噪声**（三段各自的 offset/G/λ 分布），
   替代目前的高斯噪声做训练增强和鲁棒性扫描；不需要新标签，成本最低。
   顺带得到一个现成的"噪声强度扫描轴"：0.56 / 0.17 / 0.21 光子/像素/帧三档。
4. **时间邻域作为自监督目标**：128 视频 σ=4 平滑后帧间相关 **0.978**、全程只漂 1.2 %，
   可以构成"时间留出"版的互补对，覆盖率 100 %、不需要密集标签 —— 这是对
   "自监督看得少一半"这一质疑在时间维度上的回答。256 视频漂 12.3 %，只能当去噪/
   一致性正则，不能当重建 GT。

### 结论

这批数据不是 Dryad 的同类（2-D、无 z、噪声高 15–28 倍），因此**不进入主实验的证据链**；
它的作用是给"不确定性是否可信"和"换域是否还成立"提供 Dryad 给不了的真值。
先做第 1 项（校准台），因为它把三个目前只能描述性比较的指标变成可判定指标；
用的应当是 **128 视频**（5000 帧、漂 1.2 %、两半栈相关 0.96、z 的 s.d. 0.99–1.10），
256 只能当低光子压力档，512 帧数太少且场景在变，不建议作定量用途。

## SPUR-E011 / E012 — 自监督"看得少一半"这个质疑，到底是什么在起作用

三折、同一协议 `eval.input_support=full`（测试时每一臂都拿到整个采集 = 50 % 行）。
训练侧的区别只有一件事：**看向量**与**看什么目标**。
脚本 `run_e011_e012.sh` / `eval_e011_e012.sh`，表格 `python -m spur_mpm.scripts.e011_table`，
图 `make_e012_figures.sh`（tag `_e012`）。噪声地板：跨动物 2.8 dB / 0.08 Dice，
**1 dB / 0.03 Dice 以下不声称**。

| 臂 | 训练输入 | 训练目标 |
|---|---|---|
| S1 | 50 % 行 | 100 % 密集真值 |
| **S1h** | **25 % 行（与 SS1 完全相同的行）** | 100 % 密集真值 |
| SS1 | 25 % 行 | 另外 25 % 的真实测量 |
| SS1c | 双分支 A 25 % / B 25 %（不交叠） | 各自重建对方那 25 % |
| SS1c+agree | 同上 + `dual_agree=0.3` | 同上 + 分支一致性 |

### 1. 结果

| 臂 | PSNR | Dice | E_measured | E_missing |
|---|---|---|---|---|
| S1 | 30.457 | 0.8853 | 0.0022 | 0.0341 |
| S1h | 30.287 | 0.8778 | 0.0041 | 0.0344 |
| SS1 | 24.292 | 0.7536 | 0.0491 | 0.0561 |
| SS1c | 25.409 | 0.7486 | 0.0375 | 0.0485 |
| SS1c+agree | **26.554** | 0.7570 | 0.0342 | **0.0392** |

配对 Δ 对 SS1（三折符号）：

| 臂 | ΔPSNR | ΔDice |
|---|---|---|
| S1 | +6.16 (+++) | +0.132 (+++) |
| S1h | +6.00 (+++) | +0.124 (+++) |
| SS1c | +1.12 (+−+) | −0.005 (−−+) |
| SS1c+agree | +2.26 (+++) | +0.003 (−++) |

### 2. E011：输入量不是差距的来源——但操纵确实咬到了，只是不在整图 PSNR 上

S1h 与 S1 的整图差 **−0.17 dB / −0.008 Dice，低于地板，不声称有差别**。
但把误差按"测到的行 / 没测到的行"拆开以后，S1h 在**它自己看过的那些行**上差了 **−4.82 dB**
（三折同号，45.0 → 42.3 / 46.8 → 43.8 / 53.1 → 47.3），而**没测到的行上只差 −0.10 dB**。

也就是说：把监督臂的训练输入砍半，模型确实变了（它对输入的复现能力明显下降），
但**重建能力一点没变**。所以"自监督少看一半输入"这件事是真的，却**不是** SS1 落后 S1 的原因。
真正的原因是**目标**：SS1 的目标只有 25 % 的真实测量，而 S1h 有 100 % 的密集真值。

### 3. E012：双分支互补 + 互相蒸馏——方向对，但没解决问题

- **架构单独（SS1c）**：+1.12 dB，符号 +−+，**卡在地板边缘，不声称**。
- **加一致性项（SS1c+agree）**：+2.26 dB，符号 +++，**超过地板，可以声称**。
  两路始终没有塌（`mms_a/mms_b` 从 0.86/0.30 同降到 0.040/0.042），分歧从 0.515 降到 0.015。
- **Dice 不动**：+0.003，在地板内。**PSNR 的改善没有转化成血管分割的改善**，这是本轮最重要的一条负面结果。
- 剩余差距：`S1h − SS1c+agree` = 3.73 dB / 0.121 Dice，两项都远超地板 →
  **双分支没有补上"不需要额外监督"这个缺口。**

### 4. 一个方法学发现：整图 PSNR 把两类体素混在一起平均了

出图时保护性断言挡住了 SS1c（见 §5），顺带发现整图 PSNR 的定义有问题。新增
`split_psnr`（`metrics/image_metrics.py`）与 `psnr_measured` / `psnr_missing` 两列，
用同一归一化分别算两个体素总体：

| 臂 | 整图 | 测到的行 | 没测到的行 | **测到的行占总平方误差的比例** |
|---|---|---|---|---|
| A0（零参数 Wiener） | 27.00 | **120.00** | 23.99 | 0 %（原样拷贝） |
| S1 | 30.46 | 49.29 | 27.49 | **0.7 %** |
| S1h | 30.29 | 44.47 | 27.40 | 1.9 % |
| SS1 | 24.29 | 24.92 | 23.78 | **43.5 %** |
| SS1c | 25.41 | 26.71 | 24.42 | 37.2 % |
| SS1c+agree | 26.55 | 27.26 | 25.99 | 42.7 % |

（恒等式已核验：`-10log10((10^(-p_m/10)+10^(-p_x/10))/2)` 逐臂还原整图 PSNR，误差 <0.03 dB。）

结论：**监督臂的整图 PSNR 里只有约 1 % 的平方误差落在它被喂进去的体素上；
自监督臂则有约 40 % 落在那里——它们连自己的输入都没保住。**
所以 6.2 dB 的整图差距里有约 2.5 dB 只是"愿不愿意抄输入"，而不是重建能力。

只看**任务相关的量**（没测到的行）：S1h 27.40、SS1c+agree 25.99，差 **1.40 dB**（刚过地板）；
而 Dice 仍差 **0.121**（远超地板）。
→ **自监督在"没测到的行"上已经把重建差距压到 1.4 dB，但血管分割差距没有跟着缩小。**

建议：报告 `psnr_missing`，或对所有臂统一施加零参数的 hard consistency projection
（`eval.consistency_projection=hard`，即 E009 的 dc 消融）；二者等价于把"抄输入"这一项
从能力比较里剔除。这条不改变 SS1 vs S1 的方向，只改变差距的解释与大小。

### 5. 出图脚本的一个真问题（已修）

`qualitative_figures.py` 里的保护断言要求"所有臂的输入掩码逐体素相同"，双分支臂被它挡住了：
双分支把采集到的行**对半分给两支**，每一支单独只有 25 %，而 S1/S1h/SS1 在
`input_support=full` 下都是 50 %。用任何一支的输入去画 Input 行都会误导。

修法：双分支的 Input 行画**两支的并集**（A 支看过的取 A 的，其余取真实测量），
并集恰等于整个采集 = 50 %，与其他臂一致；图注自动加"SS1c: Input = union of the two
branches (each saw half)"；sidecar 加 `input_is_branch_union`。断言同时加严到连 `y_in`
数值也要求逐臂相等。三折各 4 张图已重出，`_e012` 前缀，未覆盖主图。

### 结论与下一步

1. E011 关掉了"输入量"这个解释：**差距来自目标密度，不来自输入密度**。
2. 双分支 + 互相蒸馏是本项目目前最好的自监督方案（整图 +2.26 dB，超出地板），
   在"没测到的行"上距监督只剩 1.40 dB；**但 Dice 收益为 0**。
3. 下一步应当瞄准 Dice 而不是 dB：分别报告 `psnr_missing` 与 Dice，
   并检验分割头的失败是阈值/尺度问题（`pred_fraction` vs `ref_fraction` 已记录在
   `samples.csv`）还是拓扑问题（`n_components_pred` vs `n_components_ref`）。
4. 三折三点，只有一只留出动物，所有结论受 1 dB / 0.03 Dice 地板约束。

### 6. 为什么 dB 上去了 Dice 不动：分割失败模式是"糊成团"，不是阈值错

从 `samples.csv` 里已经记下的 `pred_fraction` / `n_components_pred` / `cl_dice`（fold 0）：

| 臂 | 前景占比 | 参考前景 | 连通域数 | 参考连通域 | Dice | clDice |
|---|---|---|---|---|---|---|
| 参考 | — | 0.278 | — | **1972** | — | — |
| S1 | 0.303 | 0.278 | **1391** | 1972 | 0.848 | 0.824 |
| SS1 | **0.557** | 0.278 | **27** | 1972 | 0.677 | 0.629 |
| SS1c+agree | 0.312 | 0.278 | **35** | 1972 | 0.654 | 0.583 |

自监督臂的预测**不是血管网络**：前景面积翻倍（SS1）或正常（SS1c+agree），
但整张图只剩 **27–35 个连通域**（参考 1972），也就是所有血管被糊成了几十个大团。
clDice 同样低（0.58–0.75 对 0.81–0.88），说明**中心线本身**就不对，不是管径/阈值问题。
SS1c+agree 修好了**面积**（0.312 ≈ S1 的 0.303），**没修好拓扑**（35 对 1391）。

这解释了为什么 +2.26 dB 换不来 Dice：dB 主要由大面积灰度吻合决定，Dice/clDice 要求
细结构连通。**下一步的损失项应当直接约束拓扑（clDice 或连通性正则），而不是继续追 PSNR。**

### 2. 结构指标为什么先返工（五个独立缺陷，逐个有测量）

原实现看着能跑，但数字是错的，错到不能用来回答"血管结构有没有恢复"：

1. **链长**用"邻域距离和的一半"：一个 200 层真实栈算出 **45 km**。改成
   枚举每条邻接边一次、按连通域求和（树状分量精确，只有含环的分量才建 MST）。
2. **节点数**数的是节点体素：240 万骨架体素里 230 万被判成节点（96%）。
   改成数**节点簇**（`label` 后取连通簇数）。
3. **分区漏边**：把节点体素挖掉后，节点—分支之间的连接边被丢掉，Y 形总长
   从 22.97 掉到 19.14（正好 `1+2√2`）。补 `_connector_length`，三部分相加才是整条骨架。
4. **二值化**用全局 Otsu：真实栈里 73% 体素过阈值，骨架化后是"面"不是"线"。
   改成逐层 Otsu，并统一在 `segment_pair` 里做。
5. **滞回阈值**默认 `low_ratio=0.6`：实测把 M2 单层前景从 0.31 泡到 0.87
   （表面）和 0.06 到 0.15（深层）。改成默认关闭（`1.0`），要用必须显式声明。

根因是**分割规则**：原始灰度 Otsu 把单层 37–55% 判成血管。改成 **Sato 管状响应**
后，同一批真实层前景 3.0%（σ=(1,2)）到 4.2%（σ=(1,2,3)），骨架节点体素占比从
95% 降到 5%，40 层真实数据算出 **662 mm/mm³**，与毛细血管密度同量级。
`segment_pair()` 现在是唯一的分割入口（响应 → 只在参考上拟合阈值 → 原样作用于
预测），`mask_vessel_metrics()` 承接"已经在掩膜上"的重合指标，谁都不能偷偷再阈值一次。

顺带：`skeleton_stats` 在 40 层真实数据上从 49 s 降到 9 s（按边界框裁切 +
向量化邻接枚举），`analyse_volume` 的整卷调用因此才可用。

### 8. 整卷结构：有学习臂 vs 双线性下限（同一门控、同一阈值）

| 指标 | 参考 | A1（下限） | S1（有学习） |
|---|---|---|---|
| Dice | — | 0.8392 | **0.8634** |
| clDice | — | 0.7424 | **0.7725** |
| 骨架 F1（1 体素容差） | — | 0.7163 | **0.7373** |
| 连通域 | 15543 | 17566（+13%） | 9785（**−37%**） |
| 节点 | 2775 | 3494（+26%） | 2232（**−20%**） |
| 链长 mm | 156.0 | 184.3（+18%） | 129.1（**−17%**） |
| 平均半径 µm | 2.48 | 2.41 | 2.58 |

两点判读，都必须按地板说：

1. **重合度**：S1 比下限高 +0.024 Dice / **+0.030 clDice** / +0.021 skelF1。
   clDice 的增益**正好压在 0.03 地板上**，Dice 和骨架 F1 在地板以下 ——
   按 E020 的规矩，这只能记为"方向一致、未达可主张门槛"，不能写成"结构上更好"。
2. **偏差方向相反**：双线性**多连**（连通域 +13%、节点 +26%、链长 +18%），
   网络**少连**（连通域 −37%、节点 −20%、链长 −17%），半径反而粗 4%。
   也就是说网络把跳过的行"补得过于干净"，把该分开的血管并到了一起；
   双线性则把不该连的接上了。两种失败模式都在拓扑上，量级相当
   （链长偏差 18% vs 17%），谁更"对"取决于下游要看什么：
   要数分支就看连通域/节点，要量总长就看链长 —— 目前两边都没有压倒性证据。

这也是为什么第一层的结论现在可以写得比之前硬：不是"网络更好"，
而是**在 y_k2 上网络的灰度增益（+1.45 dB）没有变成结构增益，
它只是把双线性的"多连"换成了"少连"**。要改变这个判断，
要么提高稀疏等级看曲线交叉，要么换指标口径（半径/长度分布而非总长）。

## SPUR-E022 — 稀疏轴阶梯（sweep / matched / floors）与等面积评估口径

E021 只在 `y_k2` 上做了六格消融。这一轮把阶梯铺开：S1 走完 Y / Z / Y+Z 三族九级，
A0/A1/S2 在 25 % 预算的三个轴上对齐，最后给**每一级**补上无学习下限。
新增 21 个 cell（13 训练 + 8 免训练），GPU 2 单卡串行约 4.2 h 训练 + 2.0 h 重打分。

### 1. 先修一个配置门（`z` 族第一轮 10 个 cell 全废）

`validate_context_depth` 拒绝 `kz>1` 却只有单层上下文的窗口：`z_k2` 每两层只有一层
被测量，单层窗口在未测量层上输入全 0，网络只能凭空造。门本身是对的，
但 `run_ladder` 从没给 `z` 族传过上下文，10 个 cell 全部在 30 s 内报错退出。

修法：按协议给**最小必需**上下文 `T = 2kz − 1`（`z_k2`/`yz_k2x2` → 3 层，
`z_k4`/`yz_k2x4` → 7 层），写进 `config.yaml` 与 `ladder.json` 的 `context` 列。
另外加 `--context-slices N` 用于 plan §3.3 要求的**同上下文对照**（run 名加 `_c7`
后缀，不覆盖最小上下文那份 cell），本轮先记着，尚未开跑。

### 2. 三处评估口径缺陷（都会让最难的协议显得最好）

| 缺陷 | 现象 | 修法 |
|---|---|---|
| `split_errors` 空总体除 `clamp(min=1)` | `z_k4` 的 `E_missing` 报 0.035，而缺失平面本身是 0.075——全测量窗口给它贡献了一个 0 | 空总体返回 `nan`，`evaluate` 不写该键，汇总只统计真正有该总体的窗口（`n_units` 可见） |
| 整体 PSNR 在 dB 空间平均 | `z_k4` 有 1/4 窗口是"被测平面本身"，误差 0 → 120 dB，把均值拉到 47.75 dB，而重建平面只有 29.5 dB | 每窗口记 `fully_measured`，汇总计数，表里该类 PSNR 打 `†` 并指向 `PSNRmiss` |
| `samples.csv` 列名取自第一行 | 第一行恰好没有 `psnr_missing`，表头被截断，后续窗口被 `DictWriter` 拒绝，5 个 `z` cell 崩溃 | 列名取所有行的并集，缺值写空 |

### 3. 等面积工作点：`★` 列（本轮最重要的口径改动）

参考阈值只从真值拟合（这条必须保留：否则各臂自己调工作点），但它把**预测的对比度
漂移**也一起算进了 Dice：`y_k4` 参考前景占 18.65 %、双线性 18.69 %、S1 只有 7.2 %，
于是 S1 的 Dice 从 0.545 掉到"比插值差 0.053"，而同一行的 MAE 却更好（0.0297 vs 0.0342）。

`match_foreground` 把同一张预测按参考前景面积取分位重切一次，得到 `dice_area` /
`cl_dice_area` / `f1_area`（表里带 `★`），**与不带星的列并排，只作补充**。
两条自限：

1. 等面积是构造出来的，糊成一团的预测也能拿到面积——所以必须和不带星的那列一起读；
2. 面积上限是响应的正值支撑（全平面取分位时，响应被压暗的管子切点会落到 0.0、整帧被判成血管——已修并加测试）。

可用性前提检验：两团同面积**随机**掩膜的期望 Dice ≈ `2f/(1+f)` ≈ 0.19（f = 0.1865），
S1 在 `y_k4` 拿到 0.640，远高于随机，说明等面积之后它仍是"血管形状"而不是被摊平的噪声。

### 5. 同预算换轴（25 %：`y_k4` / `z_k4` / `yz_k2x2`）

| S2 | 0.6426 | 0.6407 | 0.6606 | 0.0199 | 不可主张 |

这是本轮最值得记的一条：**插值的质量依赖稀疏轴（Y 轴最难，极差 0.040），

### 5b. 同上下文对照（plan §3.3）——换轴结论不是上下文长度带来的

问题：三个 25 % 协议需要的最小上下文不同（`y_k4` 1 层、`yz_k2x2` 3 层、`z_k4` 7 层），

| `z_k4` | 0.6399 / 0.6254 / 0.6470（7 层） | 同左（本来就 7 层，直接复用） |

也就是说上下文长度不是口径差异的来源，Z 轴补不回来是真的补不回来。

顺带一条要如实记的：骨架 F1★ 的极差在 7 层下**变大**了（0.0428 → 0.0637），因为
加分全部落在 Y 轴上，Z 轴不动。所以"三轴拉平"只在 Dice★/clDice★ 这两条面积口径
上成立，**骨架中心线口径上 Z 轴依然更差**（A0 0.7067 vs S1 0.6470）。

### 6. 缺层极限（plan §3.2 要求专门报告）

`z_k4` 每 4 层留 1 层：原始 5 µm 步长 → 采样层间隔 20 µm。

| | A0/A1 | S1 |
|---|---|---|
| PSNRmiss（缺层） | 24.62 dB | 25.90 dB |
| Dice★ | 0.6353 | 0.6399 |
| skelF1★ | **0.7067** | 0.6470 |

灰度上网络赢 1.28 dB，结构上只追平（+0.005），骨架中心线反而更差（−0.060）。
结论：**20 µm 层间隔下，缺层信息本身没有被网络补出来，只是平滑插值已经足够好**；
继续加大层距（`yz_k2x4` 的 12.5 %）时 S1 的绝对水平掉到 Dice★ 0.583、骨架 F1★ 0.602，
已经低于 A0（0.635）。这与 plan §3.2 对"大 Z-step 缺层不可恢复"的预判一致。

### 7. 结论

1. **可主张**：Y 方向行稀疏在 25 % 与 12.5 % 预算上，监督重建在血管结构与中心线上
   优于双线性（Dice★ +0.040 / +0.059，clDice★ +0.067 / +0.097）。
2. **不可主张**：Z 与 Y+Z 轴上的任何结构增益；50 % / 33 % 预算上的结构增益。
3. **有效但不构成结构结论**：灰度 PSNRmiss 在全部九级上都涨 1.0–1.5 dB。
   灰度增益没有同步变成结构增益，这是 E021 已经出现、这一轮被九级放大确认的现象。
4. **方法学**：不带星的 Dice 在同一批数据上给出相反结论，差别完全来自预测的对比度
   漂移；任何只看 `Dice` 的报告都会把"网络输出偏暗"误读成"结构更差"。

### 8. 结论（可以写的 / 不能写的）

1. **可写**：Y 方向行稀疏在 25 % 与 12.5 % 预算上，监督重建的血管结构（等面积 Dice★/
   clDice★）优于双线性；这一条在本轮全量重打分后方向不变。
2. **可写**：门控先验融合 + 不确定度（S2g）**没有**可测量的精度增益，却把算力抬高 17 %、
   延迟抬高 6 %——消融到此为止，不要再堆模块。
3. **可写**：插值的质量依赖稀疏轴（极差 0.0405），监督臂把三轴拉平（0.015–0.020）。
4. **不能写**：任何"某个稀疏轴更好"；`y_k2` 上任何创新点贡献；任何 < 1 dB / < 0.03 Dice
   的差异；整卷结构分数不能脱离"计分层占比 34–72 %"单独引用。
5. **仍缺**：A1 在单位 PSF 下退化为 A0（要数据驱动 PSF 估计才能让 Wiener 下限有意义）；
   训练方差未知（全部单种子单 split）；门控准则需要重做；M2 只有一只留出动物。

顺手把 PSF 的代价也量了（同一体、`wiener_fill_first`）：单位 PSF 下 **1.72 ms/volume**,

### 11. 把"报告里的断言"变成"报告里的计算"——以及它第一次跑就崩了

手册 §4.4.1 D 要求 `consistency_report.json` 写出**显示窗宽、掩膜采样语义、几何/体素间距**。
第一版做到了"写出来"，但写的是**抄进去的冻结值**：掩膜就算根本不是 `z_k4`（而是按行
抽的 `y_k4`），报告也照样写 `ok`——因为没有任何一步去比对。这与本轮前面修掉的
`projection` 常量是同一类错误：**元数据在描述自己，而不是在检验产物**。

现在三项都是重算后比对，任一不成立就 `return 2`：

| 字段 | 怎么算的 | 实测（`figures_fixed/M2_FOVII_S1_vessels/`） |
|---|---|---|
| `display_windows` | 用同一份密集参考把窗宽**再派生一次**，与冻结值逐位比 | `window_diff = 0.0`，5 个面板齐全 |
| `mask_semantics.<level>` | `measured_fraction` 对 `ideal_fraction`（容差 `2/H + 2/Z` = 0.0177）+ `z_dense`/`y_dense` 对 `kz`/`ky` | `0.25 / 0.2512 / 0.2512`，三者 `axes_ok` 全 True |

2. 让协议 spec 跟着 group 走（`SamplingSpec.to_dict()` → `ky/kz/ideal_fraction`），**缺了
   直接 `ValueError`**。选了 2，并加 `test_the_report_reads_the_protocol_spec_not_the_volume_tag`

### 14. 骨架"1 体素"到底是多少微米：容差敏感性（PR §4.3 的收口）

手册 §4.3 留了一条没关的：结构表的骨架匹配容差写的是 `tolerance_vox=1`，但体素是
**Z 5 µm / XY 0.98 µm**，所以"1 体素"在纵深方向上实际宽容了 5 倍于平面的物理距离。
`scripts/tolerance_sweep.py` 不重新推理，直接读 `structure_report` 导出的那一对
`*_{pred,ref}_mask.tif`（就是算指标用的同一对掩膜），只改匹配容差重算；微米列用各向异性
EDT，因此 Z 的 5 µm 与 XY 的 0.98 µm 在物理尺度上等价。

四卷均值（`runs/E021_ladder/tolerance_sweep/`）：

| 容差 | A1（地板） | S1 | Δ(S1−A1) |
|---|---|---|---|
| 0 µm（严格重合） | 0.3854 | 0.4513 | **+0.0659** |
| 0.98 µm | 0.6733 | 0.6951 | +0.0218 |
| 1 µm | 0.6733 | 0.6951 | +0.0218 |
| 5 µm | 0.9195 | 0.9261 | +0.0065 |
| 10 µm | 0.9795 | 0.9834 | +0.0038 |
| **1 vox（现行表口径）** | 0.7163 | 0.7373 | +0.0210 |

三件事：

1. **现行表的"1 vox"这一列与已发布的结构表逐位吻合**（S1 0.7373、A1 0.7163），说明这个
   复算没有偷偷换掉口径——它解释的是同一张表，不是另一张表。
2. **"1 vox" 比 "1 µm" 白送 0.042 分**（0.7373 vs 0.6951，S1）。差额几乎全部来自 Z 方向
   的 5 µm：各向同性的一体素球在纵深上把 5 µm 的错位也算作命中。PR 担心的正是这一点，
   现在有数了。
3. **S1 相对地板的优势随容差放宽而塌缩**：严格重合 +0.066 → 5 µm +0.007 → 10 µm +0.004。
   两种读法都成立，但含义不同：严格口径下 S1 说的是"中心线位置更准"，宽松口径下说
   的是"到血管尺度两家基本一样"。按取数纪律（0.03 Dice），现行口径的 +0.021 不能声称；
   严格口径的 +0.066 可以，但必须写明它衡量的是**中心线精度**而非拓扑正确性。

一个诚实的保留：0 µm 要求骨架体素精确重合，对两侧都过于苛刻（任何半体素偏移都算错），
它给出的是下界而不是真值。所以这张表该和 `clDice` 一起看，不应单独引用某一列。

`test_tolerance_sweep.py` 13 条测试把三件事钉住：轴向 1 体素在 1 µm 口径下必须判错、
在 5 µm 口径下必须判对；横向 1 体素在 1 µm 口径下必须判对；spacing 缺失时必须拒绝出表
而不是悄悄退回体素口径。

### 起因

但必须额外注明。同时指出 GPU0/GPU2 显存只占一半，可以并行推进。

### 查证（结论：源数据不含标定）

- `Data 3P/README.pdf` 原文："All imaging parameters are described in the manuscript
  Methods"——正文不在随数据发布的包里。
- 203 页 ZYX TIFF 的 ImageJ 头只有 `spacing=5.0`、`unit=micron`、`cf/c0/c1`、
  `XResolution=0.995403`；**没有 NA、没有发射波长、没有介质折射率、没有物镜型号**。
- 数据集 spec 里只有 `excitation_nm: 1340`、`voxel_xy_um: 0.98`、`z_step_um: 5.0`。
- 全库非图像文件只有那一个 PDF。

顺带记一个口径差：TIFF 头换算出的像素尺寸是 **0.9954 µm**，项目一直用 **0.98 µm**。
差 1.6 %（512 px 视野上 8 µm），不改变任何结论，但说明 0.98 来自论文而非文件头。

### 做法：两个独立估计器，都不许自称标定

1. **算术**（`physics/psf_estimate.py::diffraction_limited_sigma`）：单光子
   `FWHM_xy = 0.51λ/NA`、`FWHM_z = 0.88λ/(n-√(n²-NA²))`，再按 `I^N` 一阶收窄除以
   `√N`。NA 不在数据里，所以用 0.8/1.0/1.05 三个候选**全打印**，不挑一个。
2. **留出预测**（`holdout_width_scan`）：用 `y_k2` 协议抽掉一半行，那些行是**真实
   测量**；只用留下的行插值 + 反卷积，看哪一档宽度最接近被抽掉的行。只碰 fold 0
   的训练动物，脚本会拒绝落在 test 组的卷。

### 结果

| 轴 | 算术 σ（体素） | 留出预测的最优 σ |
|---|---|---|
| 横向 | 0.163–0.214（NA 1.05–0.8） | **0 µm**，9 档里每一档非零都更差 |
| 轴向 | 0.113–0.216 | **0 µm**，6 档里每一档非零都更差 |

横向 0.2 µm 就已经 −0.17 dB；0.6 µm 是 −3.48 dB。曲线在 0.8 µm 之后回升
（20.28 → 21.19 → 22.19），那是 Wiener 在 λ=0.01 下放大倍数随 σ 减小的数值行为，
不是"3 µm 的 PSF 更对"——判读时必须同时看"实际改动比例"那一列。

### 这条结论改变了什么

- identity 从"没有标定所以先默认恒等"升级为**测出来的结论**：光学 PSF 比体素还细，
  本来就没什么可反演的；而"任何反卷积都让留出预测变差"是可复现的否定证据。
- `P2_DualW` 与 `P2_DualI` 在本队列上**结构性退化**这件事，现在有数字支撑，不再
  只是方法学声明。
- 新增第三种标签 `estimated_from_data`（`physics/prior.py::PSF_SOURCES`），**故意不
  与 `calibrated_optical` 共用名字**：将来真的估出非零宽度时，用它的 summary 也不
  可能被引作"标定光学"。
- 验收人 §6 第 1 条待决项被降级：不是"再调调参数"，而是要拿到真实标定体（beads
  或仪器日志）才能改变结论。

### 不能读成什么

- 不能读成"Wiener 反卷积没用"——只说明**这批数据、这个采样**下没有可去除的模糊。
- 不能读成"PSF 已标定"。一个是假定 NA 的算术，一个是含插值低通的任务最优**有效**宽度。
- 不能读"3 µm 比 0.8 µm 好"（见上，是数值行为）。

## 2026-11-11 GPU 2 事故与"把约束写进代码"

### 发生了什么

上一轮把 E024 的两臂铺在 `GPUS=0,2` 上：`P2_Direct` 在 GPU 0，`P2_ResidualI` 在
GPU 2。验收人指出 **GPU 2 一旦被占满会让整台服务器卡死并触发无人值守重启**，会把
同机其他用户的作业一起带走。这不是"跑得慢"，是把共享机器的可用性押上去。

处置：读出每个进程的 `CUDA_VISIBLE_DEVICES` 定位归属，对 GPU 2 上的全部 5 个进程
（主进程 + 4 个 dataloader worker）发 SIGTERM；GPU 2 显存从 39 691 MiB 回落到
26 274 MiB（回到别人作业的基线），没有触碰任何不属于我们的进程。
`P2_Direct`（GPU 0）未受影响，继续训练。

**如实记录：`P2_ResidualI` 的第一次训练被人工中止（rc=143），不计入结果。** 这一条
留在日志里而不是被"重跑覆盖掉"，因为它是一次执行正确的记录——中止是调度失误造成的，
不是方法失败。它的第二次训练随后起在 GPU 3 上，run 名不变，产物目录不覆盖旧的东西
（第一次没有写出任何 `best.pt`）。

### 为什么写进脚本而不是写进文档

原来的约束只存在于人的记忆里，而它正是在记忆这一步失效的。`run_e024.sh` 现在在
**第一个作业之前**检查 `GPUS=` 列表：出现 `2` 就 `exit 2`，并打印原因。`DRY=1`
的打印分支同样拒绝——一个为 2 号卡打印命令的 dry-run，教出来的是错的命令。
`ALLOW_GPU2=1` 是唯一的出口，存在的意义是让破例成为一个看得见的动作。

`spur_mpm/tests/test_run_e024_guard.py`（6 项）钉住四条：任意位置的 `2` 都拒
（`2` / `0,2` / `2,0` / `0,1,2`）、dry-run 也拒、覆写必须显式、无 `GPUS=` 不跑。
另外两项钉 `SKIP_DONE=1` 的语义：一个 run 只有 `best.pt` **与** `<name>_test/
summary.json` 同时存在才算完成；只有 checkpoint 的是半跑，宁可重跑。

### 顺带补上的续跑能力

阶梯被打断后重开，最贵的错误是把已经跑完的几小时再跑一遍。`SKIP_DONE=1` 让
`STAGE=all` 的含义变成"把缺的补齐"，并在输出里逐个打印 `skip <name>`，所以
"这一轮到底跑了什么"仍然可读（不打印就等于把跳过藏起来了）。

### 本轮实际占用的卡与理由

| 卡 | 谁 | 我们 | 依据 |
|---|---|---|---|
| GPU 0 | 别人（~25.7 GB） | `P2_Direct` 13.4 GB | 余量 10 GB，只放一个 |
| GPU 1 | 别人（44.5 GB） | — | 余量 4.6 GB，放不下 13.4 GB 的 run |
| GPU 2 | 别人（26.3 GB） | **禁止** | 占满会卡死服务器 |
| GPU 3 | 别人（33.2 GB） | `P2_ResidualI` 13.4 GB | 余量 15.9 GB，单 run 可放 |

每张卡上都有别人的作业且在 100 % 利用率，所以**精度结论有效，延迟/吞吐/峰值显存
一律不报**——这条纪律不变，且要在结果表里写明。

### 测试

新增 6 项，全套见 `docs/PHASE1_PR2_ACCEPTANCE.md` §5 的实际数字。

### 追加（同日）：规则从"完全不用"改为"低于半满才用"

验收人补充：GPU 2 要尽量避开，但不是绝对——**显存占用不到 50 % 可以用，
一旦有一定占用就不开**。于是把硬拒绝换成占用率闸门：

```bash
GPUS=0,2 DRY=0 STAGE=dual bash spur_mpm/experiments/run_e024.sh
# refusing to use GPU 2: 26274/49140 MiB is 53.5%, at or above the 50% ceiling.
# rc=2
```

四条设计取舍：

1. **每次启动现量**，不缓存上一次的判断。"一小时前还空着一半"正是上次事故的形态。
2. **阈值含等于**：正好 50 % 算满。
3. **读不到占用率也拒绝**——"读不出来"不等于"它是空的"，而一个坏掉的
   `nvidia-smi` 返回空字符串时最容易被 `[ -z ]` 之类顺手放过去。
4. **不在 `GPUS=` 里的卡根本不探测**，否则一台坏的 `nvidia-smi` 会连带挡住
   本来就合规的卡。

当前实测：GPU 2 = 26 274/49 140 = **53.5 %**，高于阈值，所以此刻仍不开。

### 追加：显存占用改为实测入账

`train.py` 每次训练结束把本次 run 真正占住的显存写进 `final_val.json`
（`gpu_peak_allocated_mb` / `gpu_peak_reserved_mb`），并在日志里打一行。
`reserved` 是与 `nvidia-smi` 对得上的那个数，判断"两臂能否共卡"看它、留 15 % 余量。
**这是容量数字不是性能结论**：在别人作业同在的卡上量到的共占值，不得进任何
延迟/吞吐/峰值显存表格。之前"要不要并行"只能靠估，现在每一臂都有自己的数字。

单测 `test_run_e024_guard.py` 从 6 项扩到 10 项，并且通过 `NVIDIA_SMI` 注入
假命令——**钉规则，不钉机器当前状态**。全套 388 项，`EXIT=0`。

dual 臂的 hard consistency 在模型内部做，所以 `P2_DualI`/`P2_DualW` 的

### 新发现：一次 `evaluate` 写盘完成后没有退出，白占 GPU0 8.2 GB 一小时

`E024_P2_DualW_y_k2_fold0_s0_ctrlzeros` 的评估在 **22:10:25** 就写出了
`samples.csv` 与 `summary.json`（日志最后一行 `wrote ...`），但进程
（pid 2775036）一直活到 23:10 才被我发现并收掉：

| 观测 | 值 |
|---|---|
| 状态 | `S (sleeping)`，161 线程，`/proc/<pid>/stack` 不可读 |
| 线程分布 | 141 个 `futex_wait_queue_me`、17 个 `R`、2 个 `poll_schedule_timeout` |
| 5 秒内 CPU tick | 1516（约 3 核在**空转**，不是阻塞在 I/O） |
| 持有的卡 | GPU0，收掉后 `nvidia-smi` 从 33 878 → 25 651 MiB（**8.2 GB**） |

**判断：这是解释器退出阶段的挂起，不是数字的问题。** `evaluate.main()` 在
`print(f"wrote {out}")` 之后立刻 `return 0`，之后只剩 `SystemExit` 与解释器
teardown——hang 发生在那之后，而产物在之前已经落盘、且逐字段校验完整
（`n_windows=758`，12 个指标全在）。**因此该 run 的结果有效，保留进表。**

**为什么它危险，以及为什么没有改代码。** 这类挂起不影响正确性，只吞显存：
在这台四张卡都有人用的机器上，8 GB 的静默泄漏会把下一次排期推向 OOM，而
`run_e024.sh` 的 `wait` 会一直挂着等一个已经干完活的进程。所以：
`is_done` 以"`best.pt` + `_test/summary.json` 同时存在"判断完成，恰好对这种
情形免疫；但脚本本身仍会等进程退出。
**本轮的做法是记录 + 收掉，不猜原因改代码**——没有 `faulthandler` 栈
（`py-spy` 需要 sudo，此环境无权限），改 `os._exit()` 之类是在猜。
下次复现时先 `PYTHONFAULTHANDLER=1` 跑，拿到栈再修。这条已写进
`docs/PHASE1_PR2_E024_RESULTS.md` §5。

### 收集器把对照臂当成了头条臂，还数成了三只动物

`collect_results` 用 `arm` 作分组键。`P2_DualW` 与它的两个
`phys_control` 对照是**同一臂名、同一参数量**的三个 run，于是：

| 症状 | 实测 |
|---|---|
| 主表 `P2_DualW` 列拿到的是谁 | 谁先被 `next()` 碰到谁——**ctrlshuffle**，29.4031 而不是 29.4121 |
| 跨动物表 | `P2_DualW\| 3 animals \| 29.3787`——**一只动物数了三遍**，范围 [29.3209, 29.4121] 是三个变体而非三只鼠 |
| 深度分层 | `P2_DualW` 的每一层 n=480，是三个 run 的窗口平均 |

**根因不在分组函数，在记录里**：`evaluate.py` 的 summary **根本没有
`phys_control` 字段**，所以下游没有任何办法区分这三个 run。修三层：

1. `evaluate.py` 的 summary 增加 `model_control: {phys_control, consistency}`。
2. `collect_results` 的键从 `arm` 改为 `_label(run)`，对照组显示为
   `P2_DualW[ctrl=zeros]`；同一 `(label, fold)` 出现两个 run 时**报错而不是猜**——

### 旧项目"Wiener 初始化有显著增益"是怎么来的：查完了，和本轮**不矛盾**

问题来自验收：`/data2/wjb/threePM` 的 C2 说物理先验稳定增益，本轮 E024 里 `P2_W0`
和 `P2_I0` 一模一样。逐条对过源码后，结论是**协议差异，不是实现差异**。

**旧结论的可核验链路**

1. C2 = EXP-024 主矩阵，6 个 `(k_y,k_z)` 点 × 4 arm，`b4f`(FillFirst-Wiener+门控融合)
   vs `b1`(Direct)，6/6 正，+0.59…+3.36 dB（`REVIEW_v4/02_CLAIMS_EVIDENCE.md:56-66`）。
   6 个点里 kz 全 ≥ 2，**全是 yz 双轴稀疏**。
2. 那套协议里**目标先被 PSF 模糊再采样**：`PSRAS/data/observation.py:128`
   `hx = blur_3d_fft(x, cfg.psf)`；默认 `--psf_xy 1.0 --psf_z 1.5`（像素），
   `PSRAS/scripts/train.py:210-211`。而 warm start 用的是**同一个** `psf` 对象
   （`observation.py:111`）。所以旧 Wiener 解的是一个**已知核、非恒等**的逆问题。
3. 旧项目自己写明了增益的来源：C6「Wiener 增益主体来自 PSF 退卷积（EXP-021 no-PSF
   消融）：去掉 PSF 后增益基本消失」（`02_CLAIMS_EVIDENCE.md:200-206`）。
4. 旧项目也自己划了边界：N10「横向（xy/y）协议上的 Wiener 增益 ≈0 或为负」、
   N11 Y regime 物理先验大增益被证伪、N7 冻结 λ 的 Wiener 在 Y regime −11…−23 dB
   （`REVIEW_v4/05_NEGATIVE_RESULTS.md`）。

**本轮为什么必然看不到**

- PSF 是恒等，两条独立路径都指向这一点：解析（NA=0.8 → σ_xy=0.214 px、
  σ_z=0.216 px，两个都小于 1 体素）与数据扫描（σ=0 是最优；每个非零宽度都是负增益，
  −0.17…−5.72 dB）。产物在 `runs/E024_dual_prior/psf_estimate/`。
- 恒等下 `spur_mpm/physics/wiener.py:50` 直接 `if psf.is_identity: return y`，
  `P2_W0` 臂**根本没进反卷积**。可核验的强证据：`P2_I0` 与 `P2_W0` 的 `summary.json`
  除 `arm` 字段外**逐字段完全相同**（不是差得小，是同一个数）。
- 我们的 regime 正是旧项目 N10 说"增益 ≈0 或为负"的那一档：y 单轴、kz=1。

**实现有没有差异**

没有实质差异，而且我们用的是旧版**后一代**：`spur_mpm/physics/wiener.py` 文件头就写着
ported from `PSRAS/physics/wiener.py`；λ=0.01 相同；v4 的 C2 用的已经是三维
`gaussian_otf_3d` + 真 σ_z，不是最早 `dataset.py:420-480` 那个逐帧 2D、σ_lateral=1.0
固定、σ_axial 从不进入 inversion 的版本（后者被外部审查标为 P0）。
DEC-015 的 fill-first 我们也有（`wiener_fill_all`），而这是**改进**过的顺序。

唯一真实差异在**协议**：旧版把 PSF 用在两端（模糊 GT + 解先验），我们把 PSF 先估计出来
（=恒等）再用；恒等时先验就退化为插值。

**量级也说明不是同一件事**：本轮 `P2_DualW − P2_Direct = +0.178 dB`，
`P2_DualW − P2_DualI = −0.014 dB`，都在 1 dB 噪声带内；旧 C2 的效应量 +0.59…+3.36 dB
是"整栈 b4f vs 裸 b1"，不是 Wiener 地板单独贡献。

**一句话**：旧结论成立的前提是 (i) 有轴向稀疏 kz≥2、(ii) 有一个已知的非恒等 H 可解。
E024 两条都不满足，所以这是同一个物理事实的两面，不是复现失败。
