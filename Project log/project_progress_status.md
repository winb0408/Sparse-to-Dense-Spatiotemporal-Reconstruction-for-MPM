  以及「让泄漏闸门面对有泄漏的构造器时必须失败」的元测试。

  记录于 `SPUR-E000a`；**合成数据不作为任何证据**。
- 真实数据审计与隔离（SPUR-E000）：六条泄漏轴（动物 / session / FOV / 通道 / 重复文件 / 时间轴）各有代码断言；
  3 折留一鼠划分 + **逐折标定**（fold 各自 offset/scale，避免测试动物统计量回流）。
- 深度剖面（SPUR-E000b）：10 卷 1866 层，**零饱和**；但每卷 p99 由顶层到底层衰减 14–30%，
  因此深度分层必须单独报告，不能整卷平均。
- 无学习基线（SPUR-E001）：A0 = A1 = PSNR 29.06 / Dice 0.869 / clDice 0.834（三折均值）。
  恒等 PSF 下 Wiener 解即插值本身，A0≡A1 逐位相同。
- 自监督（SPUR-E003b / E005，`ky=2`，`input_support=full`）：SS1 24.29 dB / Dice 0.754，
  **比插值低 4.77 dB / 0.116 Dice（真阴性，远超噪声底）**，且 `E_measured` 0.0491（在它被给定的体素上犯错）。
  加 `dc_weight=1.0` 后 `E_measured` 降到 0.0022（与有监督臂同量级）、PSNR 28.44，
  与插值的差距 **−0.62 dB / −0.037 Dice，低于噪声门限 ⇒ 平手**；差距集中在缺失行
  （`E_missing` 0.0456 vs 插值 0.0401）。改 `selfsupervision.ratio` 无效。
  （`dc1 − S1` = −2.02 dB 是另一个、且成立的比较；历史上曾把这两个数混用过，见 E005 结果 4 的更正。）
- 采样几何复核（SPUR-E009，`ky=4`，25% 行）：A0 插值 29.06 → 27.07 dB，稀疏化确实削弱了插值；
  `dc1` 相对插值的差距 −0.62 → −0.85 dB（三折 −1.39 / −0.31 / −0.83，同向为负），
  但**两端的差距都小于 1 dB 噪声底 ⇒ 仍是"不可区分"**；且差距不是收窄而是略微拉大 0.23 dB
  （同样在噪声内，两个方向都不能主张）。SS1（无 `dc1`）恶化到 −5.17 dB、`E_measured` 0.105，
  说明"忽略输入"的失效随缺失比例单调放大。
- 同输入口径复核（SPUR-E010，`input_support=holdout`，A0 与学习臂都只拿一半测量行）：
  A0h 26.6418 / `dc1` 26.8066 / SS1 24.7550 dB ⇒ `dc1 − A0h` = +0.16 dB（逐折 −0.24 / +0.21 / +0.53）、
  Dice −0.0025，**仍在噪声内**；`dc1 − SS1` = +2.05 dB（3/3），来源是"训练期在扣下行上做一致性"
  这一项改动，作用是**阻止覆盖实测量**（`E_measured` 0.0460 → 0.0197）。
  **新正信号**：被扣下的**真实**测量行上 `dc1` 的 `E_hold` 比插值低 12%（3/3 动物：
  −0.0048 / −0.0065 / −0.0044；逐窗口 92.7% / 100% / 97.9% 更优），
  但它没有传导到 PSNR/Dice（误差迁到了 `E_missing`），且 `E_hold` 尚无标定噪声底，
  **目前只能作方向性证据**。
- 有监督上界（SPUR-E002）：S0 = PSNR 30.43 / Dice 0.8835 / clDice 0.8575；
  相对 A0 **逐折 3/3** 提升 +1.37 dB / +0.014 Dice / +0.024 clDice，且每一深度档都有收益。
  S1（+X0）与 S0 无差别（≤0.064 dB），原因同 A0≡A1：X0 在有真实光学的数据上是插值。

## 立即待办（按序）

1. **路线决策**（待项目负责人定）：MMS 在两个采样密度、两种输入口径下都与插值**不可区分**，
   采样几何不再是变量。三种走法：
   (a) 给 `E_hold` 标噪声底——若通过，MMS 价值主张改为"**保证已测量的行不被改写**"
   （保真/不外推），而不是"补全缺失行"；(b) 修选模信号后继续 MMS；
   (c) **主线转向「有监督 + 物理先验」**（S1 在两种几何下都领先插值 ≈1.4 dB，是目前唯一可复现的正收益）。
2. **修选模信号**（若继续 MMS）：E005 已证伪"用 held-out 测量损失选模"（三折 holdout loss 变好、test 变差）。
   必须先有与评估口径一致的代理，并先在 E009 上验证它与 test 的相关性；在此之前 E003/E005 的 `best.pt` 可能未选中最好一步。
3. 深度分层结论一律以血管 Dice/clDice 为准，PSNR 不作深度指标（SPUR-E001 已说明原因）。
4. README 第 4 节列出的 `Vessels plus plaques*.tif` 不在上传包内，需向提供方确认。
5. 跨动物方差约 2.8 dB PSNR / 0.08 Dice，**任何小于 1 dB / 0.03 Dice 的差异不得作为结论**。

## 已知限制（写在这里，避免日后被当成结论）

- PSF 默认恒等：真实数据已含真实光学，**不做**合成高斯再模糊；因此 Wiener 分支退化为插值，
  这是可用结论，不是 bug。
- **X0 在本数据上信息量为零**：恒等 PSF 下它就是双线性插值，S0≈S1、A0≡A1 是同一事实的两次显现。
  任何「物理暖启动带来收益」的表述必须删除或改为条件性（需真实 PSF）。
- 自监督臂评估默认 `eval.input_support=full`（给全部 M_acq）；训练时只给一半。
  同输入口径的次要结果写到 `runs_holdout/`，两者不得混在同一张表里。
  **`input_support=holdout` 必须配 `eval.holdout_baselines=true`** 才能让 A0/S1 也被扣行；
  早期漏设该开关产出的 `runs_holdout/E000_A0_fold*_test`（29.16 dB，比 full 口径还高）已删除。
- `E_measured` / `E_missing` / `E_hold` 三个量的**噪声底尚未标定**；
  在标定之前，涉及它们的任何比较只能作方向性/描述性陈述，不得作为结论。
- `virtual_sparse` 只讨论虚拟稀疏；**任何加速/降剂量声明只能在 `hardware_sparse` 下提出**。
- **held-out 测量损失不能当自监督臂的选模信号**：SPUR-E005 里三折 holdout loss 一致变好，
  test PSNR 却两折变差、`E_measured` 三折一致变差。它奖励的是"在训练密度下内插"。
- 仅 1 个测试组时 bootstrap 区间退化，已用 `ci_estimable: false` 显式标注，不得当作精度。
