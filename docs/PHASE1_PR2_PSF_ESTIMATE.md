# 这批数据的 PSF 到底能不能定：查证 + 估计（2026-11-10/11）

> 结论先说：**源数据里没有 PSF 标定**；我们用两种独立估计器补上，两者都指向
> **identity**——即"这批 stack 在当前采样下没有可分辨的光学模糊"。所以 identity
> 从"默认假设"升级为"测出来的结论"，而"Wiener 在本队列上有独立增益"这句话
> 依然**不可主张**，且现在有了可复现的否定证据。
>
> 产物：`runs/E024_dual_prior/psf_estimate/{psf_estimate.json,psf_estimate.md}`；
> 归档副本 `docs/evidence/psf_estimate_20261110/`。
> 代码：`spur_mpm/physics/psf_estimate.py`、`spur_mpm/scripts/estimate_psf.py`；
> 单测 `spur_mpm/tests/test_psf_estimate.py`（12 项）。

## 1. 查证：源数据里有什么、没有什么

| 检查项 | 位置 | 结果 |
|---|---|---|
| 数据集说明 | `Data 3P/README.pdf` | 原文：**"All imaging parameters are described in the manuscript Methods"**——Methods 不在随数据发布的包里 |
| TIFF 内部标签 | ImageJ metadata（203 页 ZYX，uint16） | 只有 `spacing=5.0`、`unit=micron`、`cf/c0/c1`、`XResolution=0.995403`；**没有 NA、没有发射波长、没有介质折射率、没有物镜型号** |
| 本项目的数据 spec | `spur_mpm/configs/data/dryad_3p_vessels.yaml` | 记录了 `excitation_nm: 1340`、`voxel_xy_um: 0.98`、`z_step_um: 5.0`；同样没有 NA |
| 原始目录里的非图像文件 | `find` 全库 | 只有 `README.pdf` 一个 |
| 沉积库本身 | Dryad `10.5061/dryad.wh70rxx2j` | 无 beads/PSF 标定体、无仪器日志 |

顺带记一个口径差异：TIFF 的 `XResolution` 换算为 **0.9954 µm/px**，而项目和 spec
一直用 **0.98 µm**。两者差 1.6 %，对 512 px 的视野是 8 µm，不足以改变任何结论，
但它说明 0.98 来源于论文而不是文件头，引用时应当写成"论文口径"。

**所以本队列的 `H` 既不是 `calibrated_optical`（没人测过），也不是
`synthetic_extra_degradation`（没人加过）。** 新增第三种标签
`estimated_from_data`（`spur_mpm/physics/prior.py::PSF_SOURCES`），
它**故意不与标定共用名字**：用它的 run summary 不得被引作"标定光学"。

## 2. 估计器一：由假定光学参数反推衍射极限

激发 1340 nm、三光子、n=1.33、voxel 0.98/5.0 µm，NA 用三个常见候选（**沉积库里
没有 NA，这三个都是假定，所以全部打印出来而不是挑一个**）：

| NA | σ_xy (µm) | σ_z (µm) | σ_xy (体素) | σ_z (体素) |
|---|---|---|---|---|
| 0.80 | 0.209 | 1.081 | 0.214 | 0.216 |
| 1.00 | 0.168 | 0.638 | 0.171 | 0.128 |
| 1.05 | 0.160 | 0.563 | 0.163 | 0.113 |

公式：单光子 `FWHM_xy = 0.51λ/NA`、`FWHM_z = 0.88λ/(n-√(n²-NA²))`，再按 `I^N`
的一阶收窄除以 `√N`（横向精确、轴向近似）。三条假定写进返回值：无散射/无像差/
无离焦、一阶 N 光子收窄、NA 与 n 不在数据里。

**关键读数不是微米数，是体素那一列：在任何合理的 NA 下，σ 都远小于一个体素**
（横向最宽 0.21 体素，轴向最宽 0.22 体素）。比体素还细的 PSF 无法从采样数据里
反演出来——**限制这批数据的是采样，不是光学**。这一条本身就足以否掉"用
显微物镜 PSF 做反卷积能提升结构"的设想，而不必依赖任何训练结果。

## 3. 估计器二：哪一档宽度最能预测"被欠采样掉的那些行"

做法：用 `y_k2` 协议抽掉一半行（这些被抽掉的行**是真实测量**），只用留下的行做
插值 `I0` 和反卷积 `W0(σ)`，再看谁更接近被抽掉的行。只用 fold 0 的
**训练动物**（M1_FOVII_S1/S2、M3_FOVI_S1/S2），4 卷 × 6 个 32×256×256 patch，
λ=0.01。脚本会拒绝任何落在 test 组的卷。

## 4. 这份结果能读成什么、不能读成什么

**能读**：

- 在 50 % 行采样下，"不对插值结果做反卷积"是预测留出测量的最优选择。也就是说
  **本队列的 Wiener 候选没有任何可测量的预测增益**，这不依赖网络、不依赖训练。
- 与估计器一合看，原因清楚：光学 PSF 比一个体素还细，本来就没什么可反演的。
- 因此 `P2_DualW` 与 `P2_DualI` 在本队列上**结构性退化**，二者之差不是"物理先验的
  贡献"，而是初始化噪声。这条现在有数字支撑，不再只是方法学声明。

**不能读**：

- 不能读成"Wiener 反卷积没用"。它说明的是**在这批数据、这个采样下**没有可去除的
  模糊。换一批带真实离焦/散射的数据，结论可以完全不同。
- 不能读成"PSF 已经被标定"。两个估计器都是估计：一个是假定 NA 的算术，一个是
  任务最优的**有效**宽度（其中还包含插值本身的低通）。
- 表里 σ=0.8 µm 之后 PSNR 又回升（20.28 → 21.19 → 22.19），**不是**"3 µm 的 PSF
  比 0.8 µm 更对"。那是 Wiener 家族在 λ=0.01 下放大倍数随 σ 减小的数值行为：
  模糊越宽，滤波器越接近恒等，退化为"什么都没做"。要判读曲线，必须同时看
  `实际改动比例` 那一列。

## 5. 后续口径

1. 主表继续跑 **identity**，理由由本文件提供（此前只是"没有标定，先默认恒等"）。
2. 任何要动 `physics.psf` 的实验，必须同时 `--set physics.psf_source=...`；
   未标注会被 `physics/prior.py` 在第一个 batch 拒绝。可用的三种标签：
   `calibrated_optical`（仍需真人标定，本队列没有）、
   `synthetic_extra_degradation`（应力测试）、`estimated_from_data`（本文件这类估计）。
3. 若将来拿到论文 Methods 里的 NA/λ，重跑估计器一即可更新上界；估计器二不依赖它。

## 6. 复现

```bash
python -m pytest spur_mpm/tests/test_psf_estimate.py -o addopts="" -q   # 12 项
python -m spur_mpm.scripts.estimate_psf --fold 0 --n-patches 6 \
  --out runs/E024_dual_prior/psf_estimate
```

CPU 约 8 分钟（4 卷 × 6 patch × 15 档宽度）。脚本不修改任何配置文件：
把估计值写进一次 run 是显式的 `--set physics.psf... --set physics.psf_source=...`。
