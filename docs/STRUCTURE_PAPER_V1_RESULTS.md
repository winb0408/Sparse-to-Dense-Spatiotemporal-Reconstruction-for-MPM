## M1 — 文献微球 FWHM 的 Gaussian 候选：预检（2026-11-19）

### 来源与换算

| 项 | 值 | 出处 |
|---|---|---|
| 微球 | 0.20 µm 荧光微球，n = 5 | Stas et al., *J. Biomed. Opt.* 31(1):016004 (2026), Methods 2.1, Fig. 1b |
| 横向 FWHM | 0.87 ± 0.12 µm | 同上 |
| 轴向 FWHM | 4.59 ± 0.48 µm | 同上 |
| 换算 | σ = FWHM / (2√(2 ln 2)) = FWHM / 2.35482 | — |
| σ（物理） | σ_xy = 0.3695 µm，σ_z = 1.9492 µm | — |
| σ（本队列网格 0.98 µm / 5 µm） | **0.377 px，0.390 z-step** | — |
| 标签 | `literature_bead_fwhm_gaussian` | 既非 `calibrated_optical`，也非 `estimated_from_data` |

**网格事实（决定了后面一切）**：轴向 FWHM 4.59 µm **小于** 5 µm 的 z 步长，即每个 FWHM
只有 0.92 个采样点（Nyquist 需要 ≥ 2）。离散核的三点权重：横向 `[0.028, 0.944, 0.028]`、
轴向 `[0.035, 0.931, 0.035]`，三维中心体素占 **0.829**。也就是说：在这个网格上，
文献 PSF 几乎是 δ 函数。

### 预检的设计

`spur_mpm/scripts/e027_psf_precheck.py`（CPU，不训练、不用 checkpoint）：

- 整卷计算，不按窗口：核在轴向有耦合（±1 面各约 3 % 质量），只看中心面会悄悄丢掉轴向部分。
- 掩膜用管线自己的 `observe` + 冻结的 `SamplingSpec`（相位 0），与实验一致。
- **λ 只在训练体上选**（`{0.005, 0.01, 0.05}`），测试体只报告、不调参。
- identity 核走同一代码路径作断言：`W0(H=I) == I0`，不成立就不允许下任何 PSF 结论。
- 真实数据严格像域：`Y = M ⊙ D`，**不对 D 做任何额外前向模糊**。

### 结果（fold 0；λ 在训练体 M1_FOVII_S1 上选）

| 协议 | 参考（I0 插值） | W0_paper | 变化 | DC 增益 | DC 归一化后 MAE | 超参考最大值体素占比 | 实测区 std |
|---|---|---|---|---|---|---|---|
| **YZ-75 %**（ky=2, kz=2） | MAE 0.05050 / PSNR 23.485 dB | MAE 0.09087 / PSNR 18.268 dB | **+79.9 % MAE / −5.22 dB** | 0.9524 | 0.10353（+105 %） | 5.67 % | 0.0654 |
| **Y-75 %**（ky=4） | MAE 0.05344 / PSNR 22.881 dB | MAE 0.08376 / PSNR 18.952 dB | **+56.7 % MAE / −3.93 dB** | 0.9524 | 0.09345（+74.9 %） | 4.72 % | 0.0582 |

两组的 identity 断言均**精确成立**（`mean|W0−I0| = 0.0`），说明算子实现自洽，上表不是实现错误的产物。

### 机制：为什么"近乎 δ"的核仍然明显改变结果

1. **σ 小 ≠ OTF 平**：σ_xy = 0.377 px 的高斯在 **Nyquist 频点**仍只剩 `H = 0.507`，
   轴向 `H = 0.520`。Wiener 算子 `conj(H)/(|H|² + λ)` 在这一频段的增益是 **1.62–1.94 倍**
   （λ = 0.05 / 0.005）。
2. **插值恰好把能量堆在这个频段**：YZ/Y 晶格每隔一行/一层采样，插值填充会在采样频率
   （＝ Nyquist）留下条带。上表的 `measured_region_std` 与 5 % 左右的"超参考最大值"就是这些条带
   被放大 1.6–1.9 倍的结果。
3. **λ 还顺带压低了整体亮度**：常数体通过算子得到 `1/(1+λ)`（λ=0.05 → 0.952）。把这一因子
   除掉后误差**更大**（+105 % / +75 %），所以这不是"只是变暗"，而是高频放大。
   训练体上 λ=0.05 被选为最优，正因为它把放大压到 1.65 倍并抵消了一部分亮度损失。

### M1b — 伤害有多少来自"先填充再反卷积"这道工序？

一个必须分开的问题：是**核错了**，还是**工序错了**？`spur_mpm` 里已有 mask-aware 的迭代反演
（`iterdc`，在数据一致性约束下迭代，而不是先造一张插值图再整体反卷积）。同一个文献核放进
不同工序，缺失区 MAE（fold 0，λ 取训练体选出的 0.05）：

| 工序 | YZ-75 % | Y-75 % |
|---|---|---|
| `I0` 插值（基准） | 0.05050 | 0.05344 |
| **fill-then-Wiener**（`wiener_fill_all`，仓库现有 W0） | **0.09087**（+80 %） | **0.08376**（+57 %） |
| mask-aware `iterdc` 8 步 | 0.07196（+42 %） | 0.08228（+54 %） |
| mask-aware `iterdc` 32 步 | 0.13093（+159 %） | 0.17525（+228 %） |
| 同一 `iterdc` 8 步，λ=0.01（YZ，单独跑） | 0.05299（+5 %） | — |

结论要分两层说，**不能合成一句"文献 PSF 让效果变差"**：

1. **工序是主要来源**：把"先插值、再整体反卷积"换成 mask-aware 迭代反演，在 λ=0.01 时把代价
   从 +140 % 压到 **+5 %**（0.1213 → 0.0530）。也就是说，仓库原来的 W0 之所以难看，很大一部分
   是它在**对一张合成出来的插值图做反卷积**，把插值条带当成了信号。
2. **核本身仍然没有增益**：即使换到最好的工序（λ=0.01、8 步），0.0530 仍**略差于**插值的
   0.0505；λ=0.05 时则明显更差。原因还是 M1 的网格事实：σ=0.377 px 的核在 Nyquist 仍有
   H=0.507，"反卷积"在这里主要是放大采样频率上的能量；迭代步数越多越接近无约束逆滤波
   （32 步 0.131），这正是必须在 8 步左右停下的经验原因。

因此对论文的说法是：**文献微球 FWHM 推出的 Gaussian 先验，在本队列的采样网格上不提供缺失区
增益；仓库原有的 fill-then-Wiener 工序会把它放大成明显退化，mask-aware 工序能把退化压到
"与插值持平略差"。** 一句"物理先验有效"或"物理先验有害"都不成立。

### 判读（按 Issue #4 §2 的停止规则）

- 这是**物理候选的负结果**：在本队列网格上，文献 FWHM 推出的 Gaussian 先验让缺失区
  MAE 恶化 57 %–80 %、PSNR 下降 3.9–5.2 dB，并引入可见振铃。
- 按停止规则：**不**为获得效果而放大 PSF，**不**开启 `DualW_paper` 重训组。
- 论文图的主对照因此是：`Sparse` / `Interpolation (I0)` / `W0_paper`（作为"文献先验在该网格上
  不可用"的证据列） / `ResidualI`（最强简单学习基线，已有 checkpoint） / `Proposed`
  （仅在已有真实 checkpoint 且配置匹配时填充，否则标 `NOT_RUN`）。
- 不得据此声称"Wiener 提升光学分辨率"——本 Issue 不涉及分辨率声明。
