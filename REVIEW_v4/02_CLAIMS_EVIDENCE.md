# 创新点与证据

五条主张，按"能写进论文的强度"排序。每条给出：主张原文、实验设计、定量证据、
定性证据、局限与反证。所有数字均为 **test split**（F0 帧 750–1500），3 seed 时
标注，val 口径见 `reports/Project_progress_status.md` 与各 run 的
`val_metrics_corrected*.json`。

约定：b1 = Direct（只给稀疏观测 Y 和掩码 M）；b2 = Bilinear 先验；b4i = IterDC 先
验 + 门控融合；b4f = FillFirst-Wiener 先验 + 门控融合。

## C1（核心）Fixed-budget Y/Z 分配律：预算应省在 z

**主张**：在相同采样预算 `B = k_y · k_z` 下，把稀疏度放在轴向（平面跳采）而不是
横向（行跳采）更有效；`(k_y,k_z) = (2,8)` 最优，`(4,4)` 次之，`(8,2)` 最差。

**设计**：EXP-024 fixed-budget 三元组，4 个 arm 各自比较同预算三点；
`(2,8)` 与 `(4,4)` 各 3 seed，`(8,2)` 单 seed（如实标注）。先验侧由 EXP-023 在无
网络条件下独立预演（1008 行扫描，24 item/组合）。

**定量证据**（test PSNR dB，B=16）：

| arm | (2,8) | (4,4) | (8,2) |
|---|---|---|---|
| b1 Direct | 35.75 | 33.14 | 29.23 |
| b2 Bilinear | 37.34 | 33.98 | 29.24 |
| b4i IterDC | **37.82** | 33.61 | 29.81 |
| b4f FillFirst-Wiener | **38.86** | 34.31 | 29.82 |
| 先验侧 P2 fill-first | 37.48 | 33.67 | 30.04 |

- `(2,8) > (4,4)` 在 b4i 上 **3/3 seed 同号**，差值 +2.0 / +3.7 / +4.2 dB；
- 排序在 4 个 arm 上完全一致（b1 35.75>33.14>29.23；b2 37.34>33.98>29.24；
  b4f 38.86>34.31>29.82）；
- 先验侧预演与网络侧排序一致——说明这不是网络训练噪声，而是采样几何本身的性质。

**图**：`figures/fig1_alloc_law.png`（左：6 点 × 4 arm 曲线；右：同预算三点柱状）。

**机制解释**（可写进论文）：轴向 PSF 模糊（σ_z = 1.5 px）造成的是"邻平面泄漏"，
只要窗口内有实测平面，网络/插值就能恢复；横向行缺失是"同平面内无信息"，只能靠
先验猜。因此稀缺预算应优先保证横向密度。

**局限（必须在论文里披露）**：

1. `k_z` 同时决定上下文窗口 `T = 2k_z − 1`（kz=8 → 15 层）。EXP-017 已证明 T 本
   身有增益，所以 `(2,8)` 的优势 **混入了上下文深度**。要严格分离"分配"与"上
   下文"，需要一个 T 匹配的对照（例如 T 固定为 7，比较 (2,8) 与 (4,4)）。这是当
   前证据链上最容易被审稿人打的一环，建议补做。
2. `(8,2)` 只有单 seed。效应量（相对 (2,8) −8 dB）远大于 seed 噪声，方向可信，
   但严格判据未被满足。
3. 只在 B=16、`k ∈ {2,4,8}` 网格上验证；B=8 / B=32 未测，分配律是否随预算平移
   未知。

## C2 Wiener 家族物理先验 + 门控融合 优于 Direct

**主张**：在 yz 双轴稀疏下，物理先验（FillFirst-Wiener / IterDC）作为额外输入通道
交给门控融合网络，相对只给稀疏观测的 Direct 网络有稳定增益——**6/6 组合为正，
+0.5 ~ +3.4 dB**。

**设计**：EXP-024 主矩阵，6 个 `(k_y,k_z)` 点 × 4 arm，40 run；`(2,8)` 和 `(4,4)`
3 seed，其余单 seed；val/test 双口径。

**定量证据**（test PSNR dB，括号为相对 b1 的增益）：

| (ky,kz) | b1 Direct | b2 Bilinear | b4i IterDC | b4f FillFirst |
|---|---|---|---|---|
| (2,2) | 37.70 | 38.78 (+1.08) | 40.91 (+3.21) | **41.06 (+3.36)** |
| (2,4) | 37.54 | 39.07 (+1.53) | 39.04 (+1.49) | **40.45 (+2.91)** |
| (2,8) | 35.25 | 36.86 (+1.61) | 37.22 (+1.97) | **37.96 (+2.71)** |
| (4,2) | 33.07 | 34.14 (+1.07) | **34.47 (+1.40)** | 34.40 (+1.33) |
| (4,4) | 32.94 | 33.78 (+0.84) | 33.91 (+0.97) | **34.17 (+1.23)** |
| (8,2) | 29.23 | 29.24 (+0.01) | 29.81 (+0.58) | **29.82 (+0.59)** |

**图**：`figures/fig3_gain_over_direct.png`（逐点增益柱状）；
`figures/qual_yz_2x8.png`（重建对比）、`figures/qual_yz_2x8_err.png`（绝对误差
图，统一色标 0–0.12）、`figures/xz_yz_2x8.png`（XZ 截面，可见网络如何在实测平面
之间补插）。

**局限**：

1. 增益随采样变容易而收窄：`(8,2)` 只有 +0.59 dB。主张应写成"在中等以上稀疏度下
   稳定增益"，不能写成"处处大幅增益"。
2. Y（纯横向稀疏）regime 下增益小得多（EXP-022：Bilinear 先验 K2 +1.5 → K16 +0.16
   dB），而冻结 λ Wiener 在 Y regime 下直接崩坏（−11 ~ −23 dB）。所以"物理先验有
   益"是 **YZ 专属结论**，跨 regime 泛化必须另行论证。
3. 单数据集、无外部基线网络对照（v3 期的外部仓库对照 EXP-020 只在 z/xyz 情境做过，
   v4 未重做）。

## C3 先验好 ≠ 网络好（机制性发现）

**主张**：先验自身的 PSNR 排序不能预测网络端收益。EXP-023 中 IterDC 先验在 5/6 点
不劣于 FillFirst-Wiener（在 (2,2)/(4,2)/(4,4)/(8,2) 更高），但把它接进网络后，
**b4f（FillFirst-Wiener）在 6/6 点不劣于 b4i**，在 (2,4)/(2,8) 还显著更好（−1.41 /
−1.04 dB 的 b4i−b4f）。

**定量证据**：

| 点 | 先验 P4 − P2 (dB) | 网络 b4i − b4f (dB) |
|---|---|---|
| (2,2) | +0.11 | −0.15 |
| (2,4) | −0.74 | −1.41 |
| (2,8) | −1.22 | −1.04 |
| (4,2) | +0.33 | +0.07 |
| (4,4) | +0.09 | −0.26 |
| (8,2) | +0.23 | −0.01 |

**图**：`figures/fig2_prior_vs_network.png`（三个子图：先验侧排序、网络侧排序、两侧
差值符号对比）。定性对比见 `figures/qual_yz_2x8.png` 的 b4i 与 b4f 两列。

**机制解释**：IterDC 先验已接近 data-consistent 解，与网络互补性弱；FillFirst 保
留"结构化但可校正"的偏差（退卷积残差 + 轴向插值误差），门控融合能吸收更多。这
与 EXP-022 结果 4"网络能吃掉 −23 dB 的垃圾先验而不崩"是同一机制的两种表现——
**融合机制偏好可学习的偏差，而不是高保真但不可学的先验**。

**局限**：多处差值在 0.1–0.3 dB 量级，落在 seed 噪声内（(2,8)/(4,4) 的 sd 为
0.2–0.8 dB）。这个主张的强度应定为"方向性机制发现"，不宜表述为"严格排序反转"。
真正统计显著的只有 (2,4)/(2,8) 两点。

## C4 统一模型跨 acquisition regime

**主张（拆成两句，强度不同）**：

- **C4a（成立）**：一个统一网络/一套权重可以同时覆盖 Y / YZ / XYZ 三种 regime，
  绝对性能 33.4–34.6 dB，相对"专训模型被直接拿去做别的 regime"（跨迁移）优势明显
  （专训迁移掉 1.4–2.6 dB，最多 24 dB）。
- **C4b（未达标，如实披露）**：这个统一模型**不能**追平在目标 regime 上重新专训的
  模型——差 0.5–1.2 dB。

**定量证据**（test PSNR dB，3 seed 均值）：

| 模型 | Y (K=4) | YZ (4×4) | XYZ (4×4) |
|---|---|---|---|
| SY（专训 Y） | **34.23** | 31.99 | 13.75 |
| SYZ（专训 YZ） | 33.21 | **33.55** | 12.20 |
| SXYZ（专训 XYZ） | 23.53 | 23.61 | **35.24** |
| U15（统一，15 点） | 33.43 | 33.71 | 34.55 |
| U_noAZ（统一，9 点，无轴向先验） | 34.04 | 34.03 | 9.92 |
| U15W（1:1:2 加权，EXP-028） | 33.17 | 33.57 | 34.59 |

- gate 判读：YZ 套件 −0.38 / +0.09 / +0.23（达标）；Y 套件 −0.54 / −0.62 / −0.74
  （超线 0.04–0.24 dB，临界未达）；XYZ 套件 −1.15 / −0.61 / −0.83（3/3 未达）。
- EXP-028 把 XYZ 采样权重从 40% 提到 50%，XYZ 增益 ≈ 0（+0.12 / −0.42 / +0.11），
  Y 反而付 −0.63 / −0.65 / +0.15 → **"稀释由份额主导"假设被证伪**，残余差距归因
  到容量/任务间干扰。

**图**：`figures/fig4_unified_cross_transfer.png`（左：4 模型 × 3 套件；右：统一
变体对比，可见 U_noAZ 在 XYZ 崩到 9.9 dB——轴向物理先验是 XYZ 能工作的关键）；
`figures/qual_univ_{y_K4,yz2_K4x4,xyz2_K4x4}.png`（定性对比）。

**为什么值得写**：U_noAZ 在 XYZ 上 9.9 dB 这一条，是"物理先验通道而非学习式轴向
交互承载跨 regime 泛化"的直接证据，也是 EXP-025 里 A_Z 适配器两轮证伪的延伸——证
据链是完整的：全层 3D 有害（EXP-012/013）→ 轻量适配器无益（EXP-025）→ 关掉先验
通道则崩溃（EXP-027/026）。

**局限（论文里必须写）**：

1. 公平基线是"重训专训模型"，U15 在这个比较下是输的。统一模型的卖点是"一次训练、
   一套权重覆盖三协议"，属**工程便利性**，不是精度优势。
2. 0.6–1.2 dB 的差距不是噪声，但也不是架构性失败——EXP-028 证明它不随采样权重移
   动，指向容量。两阶段训练（U_noAZ 预训练 → XYZ 微调）是未验证的候选。

## C5 噪声鲁棒性（EXP-027，零训练复评）

**主张**：① 退化随噪声单调，且存在噪声天花板；② XYZ 混入造成的稀释是容量问题，
不是噪声稳健性问题；③ 干净训练的模型在噪声下**放大噪声**（比自己的 x0 先验还低
2–5 dB），但仍高于原始噪声输入 4–8 dB。

**证据**（5 个评估点 × 3 个噪声栈，90 次零训练 reval）：

| 点 | F0 | F1 | F2 | F3 |
|---|---|---|---|---|
| y-K4 (U15) | 33.43 | 27.10 (−6.33) | 19.81 (−13.62) | 16.95 (−16.48) |
| yz2-4x4 (U15) | 33.71 | 27.65 (−6.06) | 21.14 (−12.57) | 18.47 (−15.24) |
| xyz2-4x4 (U15) | 34.55 | 27.95 (−6.61) | 21.23 (−13.33) | 18.27 (−16.28) |
| xyz2-4x4 (U_noAZ，零样本) | 9.92 | 10.19 | 10.00 | 9.74 |

- F1（残差 std 0.072）下所有点收敛到 **26–28 dB**——噪声水平而不是采样稀疏度成为
  约束，干净协议下的 severity 排序被抹平；
- U15 与 U_noAZ 的噪声稳健性无差异（|Δ| < 0.5，符号混合）→ 稀释是容量问题；
- x0 先验在噪声下的退化远小于网络输出（y-K4 F2：x0 23.38 vs 网络 19.81）。

**图**：`figures/noise_curve.png`（5 点退化曲线 + x0 先验 + 噪声输入参考线）、
`figures/panel_{y_K2,y_K4,y_K8,yz2_K4x4,xyz2_K4x4}.png`（行 = F1/F2/F3，
列 = GT/噪声原始/稀疏 Y/X0/U15/U_noAZ）。

**局限**：这是**事后评估**，训练数据仍近似干净——F1 天花板是训练策略的产物，不是
方法上限。噪声感知训练（合成噪声增广或混入 F1–F3）是明确候选，预期能收回 2–5 dB
的一部分，但**尚未预注册、尚未执行**。

## C6（v3 期遗留，机理仍成立）

- **3PM 省时采样的信息瓶颈在轴向**（EXP-016/020）：横向协议下物理先验增益 ≈ 0 或
  为负；轴向稀疏下才有大幅增益。
- **Wiener 增益主体来自 PSF 退卷积**（EXP-021 no-PSF 消融）：去掉 PSF 后增益基本
  消失。
- **residual 设计、全层 3D 网络、video3d、零初始化轴向适配器全部被证伪**
  （EXP-015 系 / EXP-012 / EXP-013 / EXP-014 / EXP-018 / EXP-025）。

这些是"排除法"证据，写论文时用于支撑架构选择，不作为创新点。
