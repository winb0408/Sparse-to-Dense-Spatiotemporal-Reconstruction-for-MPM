# E020：固定的单折队列（有监督主线第一层）

**这不是多折交叉验证。** 从这一层开始只跑一个固定的划分：训练 / 验证 / 测试
一次定死，之后所有臂、所有稀疏等级、所有对比方法都在这同一个队列上评估，
不再重抽。理由：跨动物方差约 2.8 dB PSNR / 0.08 Dice，三种折法之间的差异
大部分是这个方差，而不是方法差异；反复重划只会提高"抽到好看数字"的机会。

- 划分文件：[`split.json`](split.json)，指纹 `98379c29…f3b3453`
- 队列索引：`data_local/dryad_cache/index_cohort.json`
- 标定：`data_local/dryad_cache/cohort/calibration_m2heldout.json`
  （**只在训练集 M1_FOVII + M3_FOVI 上拟合**；原来的 `index.json` 与
  `calibration_fold{0,1,2}.json` 保持不动，用于复现已归档的 E011/E012）
- 划分命令：

```bash
python -m spur_mpm.scripts.make_split \
    --index data_local/dryad_cache/index_cohort.json \
    --mode holdout --test-groups mouse_id:2 --val-units 1 --seed 0 \
    --out spur_mpm/experiments/E020_cohort/split.json
```

| 角色 | 样本 | 数量 |
|---|---|---|
| 训练 | M1_FOVII_S1/S2, M3_FOVI_S1/S2 | 4 卷（2 鼠） |
| 验证 | M1_FOVI_S1/S2 | 2 卷（与训练同鼠，不同视野） |
| **测试** | **M2_FOVI_S1/S2, M2_FOVII_S1/S2** | **4 卷（整只鼠，2 视野 × 2 次）** |

测试集是**一整只鼠**，训练与验证里没有任何 M2 的样本 —— 这是"跨动物泛化"，
而不是"跨视野插值"。验证集故意留了训练鼠的另一个视野，用来在训练过程中
观察"同鼠新视野"与"新鼠"的差距，但它**不参与任何结论**。

## 为什么留 M2 —— 并把这个选择的偏差写在明面上

选择依据是已归档的三折结果里每只鼠作为留出动物时的表现：

| 留出动物 | 折 | PSNR (dB) | Dice | 样本数 | 队列完整度 |
|---|---|---|---|---|---|
| M1 | fold0 | 30.464 | 0.848 | 782 | 2 视野 × 2 次 |
| M2 | fold1 | 28.921 | **0.917** | 758 | 2 视野 × 2 次 |
| M3 | fold2 | **31.984** | 0.892 | 326 | **仅 1 个视野** |

三条理由：

1. **队列完整度**：M3 只有一个视野（FOVI，158/168 层），无法用它检验跨视野表现，
   而跨视野恰恰是这个队列要说明的第一件事。M1 与 M2 都完整。
2. **结构指标**：M2 的 Dice 最高（0.917），意味着"血管结构能被重建"这件事在
   M2 上最有说服力 —— 这正是第一层要验证的命题。
3. **PSNR 最低**：M2 的 PSNR 是三只里最低的（28.9 dB），所以展示出来的不是一张
   处处最好看的表。

**偏差声明**：用一只鼠自己的历史成绩来选择"它在测试集上效果最好"，这是
选择性偏差。上面的三行原表就是为此而留 —— 读者可以自己判断差别有多大
（跨动物 3.06 dB / 0.069 Dice，其中 PSNR 差异已在噪声地板量级）。
真正的修正在于**只用一个固定队列，并且只在它上报一次**；如果后续需要更强的
泛化结论，再补一只鼠的第二折，而不是回头改这一折。

## 这一折要回答的问题

1. 三个创新点（X0 热启动 / U 头 / 门控融合）在同一稀疏等级上各贡献多少，
   在**血管骨架**上是否仍然成立（不是只看 PSNR）。
2. 稀疏到什么程度开始失效：`y_k2 → y_k8`、`z_k4`、`yz_k2x2` 的曲线。
3. 三种稀疏家族在**相同采集预算**（25%：`y_k4` / `z_k4` / `yz_k2x2`）上
   谁更划算 —— 这是采集协议建议，不只是方法比较。

## 评估约定（不要违反）

- 跨动物方差 2.8 dB / 0.08 Dice，**小于 1 dB / 0.03 Dice 的差异不作结论**。
  M2 单折只有一个动物，所以本折的置信区间来自**样本级 bootstrap**
  （`metrics/statistics.py`），不是动物级。
- 分层（按深度）结论只用 `dice` / `cl_dice` / 骨架指标，**不用 PSNR**：
  深层信号弱，PSNR 系统性偏低与结构无关。
- 结构结论看 `metrics/skeleton.py` 的链长 / 分支 / 节点 / 端点，
  对照 `export_imagej_mask` 导出的 TIFF 在 ImageJ 里手核。
- **分割规则固定为管状响应（Sato vesselness）+ 参考侧阈值**，见
  `metrics/vessel.py:segment_pair`。不用原始灰度 Otsu：实测它把单帧
  37–55% 判成血管，骨架化后 95% 体素是节点（那是"面"不是"线"），
  每根血管的拓扑统计全部失真。两条查表的区别要记住：
  逐**帧**评估（`evaluate`）用 2-D 响应（前景约 19%），
  逐**卷**评估（`structure_report`）用 3-D 响应（前景约 2–4%）——
  两种表各自内部可比，不要跨表比较绝对 Dice。
- `E_measured` / `E_missing` / `E_hold` 没有标定地板，只作相对比较。
